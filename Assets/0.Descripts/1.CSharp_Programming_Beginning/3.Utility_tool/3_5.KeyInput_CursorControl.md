# [실용 도구] 5. 키 입력·커서 제어 (Console Input & Cursor)

## 1. 키 입력과 커서 제어란?
지금까지의 콘솔 프로그램은 위에서 아래로 순서대로 실행되고 끝나는 일방적인 소통이었습니다. 하지만 사용자의 키보드 입력을 실시간으로 감지하고 화면의 원하는 위치에 글자를 그릴 수 있다면, 딱딱한 콘솔 창이 하나의 움직이는 게임판으로 변신합니다.

> **보이지 않는 격자무늬 종이와 펜**
> * **`Console.SetCursorPosition(x, y)`** : 펜을 종이의 특정 (x, y) 좌표로 이동시킵니다.
> * **`Console.Write(...)`** : 펜이 있는 바로 그 위치에 글자를 씁니다.
> * **`Console.ReadKey(true)`** : 사용자가 키를 누르는 순간, 엔터(Enter)를 치지 않아도 즉시 감지합니다.

**왜 필요한가?**\
유니티 같은 거대한 그래픽 엔진 없이도, 이 기능들만 조합하면 텍스트 기반의 RPG 게임, 인터랙티브한 메뉴 시스템, 실시간 서버 모니터링 대시보드 등을 훌륭하게 만들 수 있습니다.

---

## 2. 핵심 요약

| 개념 | 한 줄 설명 |
| :--- | :--- |
| **`Console.ReadKey(true)`** | Enter 없이 즉시 키를 감지합니다. (`true`는 입력한 키를 화면에 표시하지 않음) |
| **`ConsoleKeyInfo`** | `ReadKey`의 반환 객체. `.Key`(논리 키워드)와 `.KeyChar`(실제 문자)를 가짐 |
| **`Console.SetCursorPosition(x, y)`**| 출력할 좌표를 지정합니다. `(0, 0)`이 화면의 **맨 왼쪽 위**입니다. |
| **`Console.CursorVisible = false`** | 화면에서 깜빡이는 커서(밑줄)를 숨깁니다. (게임 시야 방해 방지) |
| **`Console.KeyAvailable`** | 현재 눌린 키가 있는지 확인만 하고 흐름을 멈추지 않음 (실시간 게임용) |
| **`Thread.Sleep(ms)`** | 지정한 밀리초(ms)만큼 실행을 멈춤 (게임 속도/프레임 조절용) |

## 3. 세부 개념 및 원리

### 3.1 실시간 키 입력 ㅡ `ReadKey()`
`ReadLine()`은 사용자가 Enter를 칠 때까지 기다리지만, `ReadKey()`는 누르는 즉시 반응합니다.
```csharp
ConsoleKeyInfo keyInfo = Console.ReadKey(true); // true: 화면에 문자 안 찍힘

var key = keyInfo.Key;       // 어떤 키인가? (예: ConsoleKey.UpArrow, ConsoleKey.A)
var ch  = keyInfo.KeyChar;   // 실제 문자는? (예: 'A', '1')
```

### 3.2 게임 루프 패턴 (Game Loop)
모든 게임은 근본적으로 다음의 3단계를 초당 수십 번씩 무한 반복합니다.
1. **입력 (Input)** : 플레이어가 어떤 키를 눌렀는가?
2. **갱신 (Update)** : 좌표, 체력, 상태 등을 변경한다.
3. **그리기 (Render)** : 화면을 지우고 변경된 상태를 새로 그린다.

### 3.3 잔상(고스트) 문제와 해결 기법
캐릭터(`@`)가 오른쪽으로 이동할 때, 이전 위치에 있던 `@`를 지워주지 않으면 화면에 `@@@@@` 처럼 잔상이 남습니다.\
초보자들은 이를 해결하려고 `Console.Clear()`를 매 프레임 호출하지만, 이는 화면 전체를 미친 듯이 깜빡거리게 만듭니다 (Flickering).\
**해결책**: 이동하기 직전에 **내가 있던 이전 자리에 공백(`" "`)을 출력해서 지우고**, 새 자리로 가서 그리는 것이 고전 최적화의 핵심입니다.

## 4. 코드로 보는 콘솔 제어

### 4.1 기본적인 커서 이동과 색상
```csharp
Console.Clear();
Console.CursorVisible = false; // 깜빡이는 커서 숨기기

// 좌표 이동 (X: 가로, Y: 세로)
Console.SetCursorPosition(10, 5); 

// 글자 색상 변경
Console.ForegroundColor = ConsoleColor.Yellow;
Console.Write("이곳에 노란색 텍스트가 찍힙니다");

// 색상을 원래대로 복구 (필수 안전 습관)
Console.ResetColor(); 
```

### 4.2 UI 패턴: 콘솔 화살표 메뉴 시스템
가장 많이 쓰이는 콘솔 메뉴 선택 시스템입니다. (위아래 방향키로 이동, 엔터로 선택)
```csharp
string[] menu = { "1. 게임 시작", "2. 환경 설정", "3. 종료" };
int selectedIndex = 0;

while (true)
{
    Console.Clear();
    Console.WriteLine("=== 메인 메뉴 ===\n");
    
    // 메뉴 그리기
    for (int i = 0; i < menu.Length; i++)
    {
        if (i == selectedIndex)
        {
            Console.ForegroundColor = ConsoleColor.Cyan;
            Console.WriteLine($">> {menu[i]}"); // 선택된 항목 강조
            Console.ResetColor();
        }
        else
        {
            Console.WriteLine($"   {menu[i]}");
        }
    }

    // 입력 대기 (여기서 프로그램이 멈춤)
    ConsoleKey key = Console.ReadKey(true).Key;

    // 상태 갱신 (선택 인덱스 이동 및 클램프 처리)
    if (key == ConsoleKey.UpArrow) 
        selectedIndex = Math.Max(0, selectedIndex - 1);
    else if (key == ConsoleKey.DownArrow) 
        selectedIndex = Math.Min(menu.Length - 1, selectedIndex + 1);
    else if (key == ConsoleKey.Enter)
        break; // 루프 탈출 후 선택된 메뉴 실행
}
Console.WriteLine($"\n[시스템] {menu[selectedIndex]}을(를) 선택했습니다.");
```

## 5. 실전 활용: 턴제 vs 실시간 게임 루프

### 5.1 턴제 방식 (Turn-based)
사용자가 키를 누를 때까지 세상이 멈춰있습니다. (체스, 소코반, 전통 로그라이크)
```csharp
int playerX = 10, playerY = 5;

while (true)
{
    Console.SetCursorPosition(playerX, playerY);
    Console.Write("@");

    // 프로그램 일시 정지 (키 입력 대기)
    ConsoleKeyInfo key = Console.ReadKey(true);

    Console.SetCursorPosition(playerX, playerY);
    Console.Write(" "); // 이전 자리 지우기

    if (key.Key == ConsoleKey.RightArrow) playerX++;
    else if (key.Key == ConsoleKey.LeftArrow) playerX--;
}
```

### 5.2 실시간 방식 (Real-time)
내가 가만히 있어도 세상(적, 미사일)은 계속 움직여야 합니다. (테트리스, 액션 게임)
```csharp
using System.Threading; // Thread.Sleep 사용을 위해 필요

int px = 10, py = 5;

while (true)
{
    Console.SetCursorPosition(px, py);
    Console.Write("@");

    // KeyAvailable: 눌린 키가 있는지 묻기만 하고 바로 통과함 (논블로킹)
    if (Console.KeyAvailable)
    {
        ConsoleKeyInfo key = Console.ReadKey(true);
        Console.SetCursorPosition(px, py);
        Console.Write(" "); // 지우기

        if (key.Key == ConsoleKey.RightArrow) px++;
        else if (key.Key == ConsoleKey.LeftArrow) px--;
    }

    // 몬스터는 내가 키를 안 눌러도 알아서 움직임 (AI 로직)
    // Monster.Update();

    // 컴퓨터가 너무 빠르지 않게 0.05초 대기 (초당 20프레임 속도 유지)
    Thread.Sleep(50); 
}
```

## 6. Unity에서는 어떻게 쓸까?

Unity는 C# 콘솔의 **"실시간 게임 루프"** 를 엔진 내부에서 알아서 돌려줍니다.

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    public float moveSpeed = 5f;

    // Unity가 알아서 무한 루프(while)로 초당 60번씩 호출해 주는 Update
    void Update() 
    {
        // 1. Console.KeyAvailable + ReadKey 역할을 Unity Input 클래스가 대신함
        if (Input.GetKeyDown(KeyCode.Space))
        {
            Debug.Log("점프");
        }

        // 축(Axis) 입력 방식 (부드러운 이동)
        float h = Input.GetAxis("Horizontal"); // A/D 또는 좌우 방향키
        float v = Input.GetAxis("Vertical");

        // 2. Console.SetCursorPosition 역할을 Transform이 대신함
        transform.Translate(new Vector3(h, v, 0) * moveSpeed * Time.deltaTime);
        
        // 3. Console.Clear()나 잔상 지우기는 그래픽 카드가 알아서 처리해 줌
    }
}
```

## 7. 실습 문제 및 복습

**Q1. `Console.ReadLine()`과 `Console.ReadKey(true)`의 결정적 차이는 무엇인가요?**
> * `ReadLine()`: 글자를 치고 반드시 **Enter 키**를 쳐야 프로그램으로 입력이 넘어옵니다. 텍스트 정보(이름, 채팅) 입력에 씁니다.
> * `ReadKey(true)`: 방향키나 알파벳 등 건드리는 **즉시** 반응하여 프로그램으로 넘어옵니다. 게임 조작에 필수적이며, 매개변수 `true`는 화면에 입력된 글자(찌꺼기)가 표시되지 않게 막아줍니다.

**Q2. 콘솔에서 이동하는 캐릭터를 만들 때, `Console.Clear()`를 `while`문 안에서 매번 호출하면 안 되는 이유는 무엇인가요?**
> 화면 전체의 텍스트를 지웠다가 다시 그리는 찰나의 순간 동안 모니터가 빈 화면을 렌더링하게 되며, 이것이 1초에 수십 번 반복되면 화면 전체가 심하게 깜빡이는(Flickering) 현상이 발생하여 눈이 아픕니다.

**Q3. 캐릭터가 이동할 때 깜빡임(잔상) 없이 부드럽게 움직이게 하려면 어떻게 해야 하나요?**
> 전체 화면을 지우는 대신, **이동하기 직전의 좌표(`x, y`)로 커서를 옮긴 후 공백(`" "`)을 출력**하여 내가 있던 자리만 지우개로 살짝 지우고, 새로운 좌표로 이동하여 캐릭터(`@`)를 그려야 합니다.

## 8. 주의사항 및 안전 습관

* **`CursorVisible = false`는 필수**: 이 속성을 끄지 않으면 내가 그리는 글자 밑에서 하얀 커서가 계속 깜빡거려 게임의 몰입도를 심각하게 떨어뜨립니다.
* **좌표가 콘솔 창 밖을 넘어가면 터진다**: `x` 좌표가 0보다 작아지거나 `Console.WindowWidth`를 초과한 채로 `SetCursorPosition`을 호출하면 바로 크래시(예외)가 납니다. 반드시 `Math.Clamp()`로 화면 경계를 벗어나지 않게 가둬야 합니다.
* **키 버퍼(Key Buffer) 주의**: `Thread.Sleep`이 길게 걸려 있을 때 키보드를 연타하면, 눌린 키들이 줄을 서서 대기합니다. 필요하다면 루프 안에서 안 쓰는 키 입력을 비워주는 로직이 필요할 수 있습니다.
