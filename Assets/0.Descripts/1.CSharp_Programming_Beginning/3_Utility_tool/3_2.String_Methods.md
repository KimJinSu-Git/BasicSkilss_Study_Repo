# [실용 도구] 2. 문자열 활용 (String Methods)

## 1. 문자열 활용이란?
`string`이 한 번 만들어지면 변하지 않는 '돌판(불변성)'과 같다고 배웠습니다. 그렇다면 이 돌판의 내용을 검색하거나, 일부를 잘라내고, 특정 단어를 바꿔서 새로운 돌판을 만들려면 어떻게 할까요?

> **마법 도구 세트**\
> C#의 `string` 타입은 불변성을 유지하며 텍스트를 가공하는 강력한 마법 도구들을 제공합니다.
> * **`Contains()` / `IndexOf()`** : 돋보기  (특정 단어가 있는지 찾기)
> * **`Replace()`** : 망치와 정 (특정 글자를 바꿔 새로운 돌판 생성)
> * **`Split()`** : 칼 (구분자를 기준으로 여러 조각으로 자르기)
> * **`string.Join()`** : 접착제 (잘린 조각들을 다시 하나로 붙이기)

이 도구들은 **원본 돌판은 그대로 두고, 항상 가공된 '새 결과물(새 돌판)'을 반환**한다는 점이 핵심입니다.

**왜 필요한가?**\
실무 코드의 절반은 텍스트 처리입니다. 사용자 아이디 입력 검증, 에러 로그 분석, 파일 경로 파싱, 기획 데이터(CSV) 처리 등 문자열 메서드 없이는 게임 데이터를 다룰 수 없습니다.

## 2. 핵심 요약

| 카테고리     | 메서드 | 한 줄 설명 |
|:---------| :--- | :--- |
| **검색**   | `Contains`, `IndexOf`, `StartsWith`, `EndsWith` | 부분 문자열의 존재 여부 및 위치 확인 |
| **변환**   | `ToUpper`, `ToLower`, `Trim` | 대소문자 통일 및 양옆 공백(찌꺼기) 제거 |
| **추출**   | `Substring(start, length)` | 원하는 시작점부터 일부분만 잘라낸 새 문자열 |
| **치환**   | `Replace(old, new)` | 특정 문자/단어를 교체한 새 문자열 |
| **분할**   | `Split(separator)` | 지정한 구분자로 잘라서 **문자열 배열(`string[]`)** 반환 |
| **결합**   | `string.Join(glue, array)` | 배열 요소들을 구분자(접착제)로 합쳐 **하나의 문자열** 반환 |
| **공통** | ㅡ | **모두 원본은 유지하며, 새 문자열을 생성해 반환함** |

## 3. 세부 개념 및 팁

### 3.1 검색 ㅡ 무엇이 있는지 확인
```csharp
string text = "Hello, World!";

bool has = text.Contains("World");    // 포함 여부 (true)
int first = text.IndexOf("o");        // 첫 'o'의 위치 인덱스 (4), 없으면 -1 반환
int last = text.LastIndexOf("o");     // 마지막 'o'의 위치 인덱스 (8)
bool head = text.StartsWith("Hello"); // 시작하는 단어가 맞는지 (true)
```

> **팁: 대소문자 무시 검색 (`OrdinalIgnoreCase`)**\
> `text.Contains("world")`라고 치면 대소문자가 달라 `false`가 나옵니다. 이때 옵션을 주면 대소문자를 무시하고 찾아줍니다\
> `text.Contains("world", StringComparison.OrdinalIgnoreCase);` // true

### 3.2 추출과 치환 ㅡ 새 돌판 만들기
```csharp
// 인덱스 0부터 5글자를 잘라냅니다.
string part = text.Substring(0, 5);  // "Hello"

// "World"를 "C#"으로 바꾼 새 문자열을 반환합니다.
string fixedText = text.Replace("World", "C#"); // "Hello, C#"
```

### 3.3 분할과 결합 ㅡ 가장 강력한 도구 (CSV 파싱의 핵심)
```csharp
string csvData = "전사,마법사,도적";
string[] jobs = csvData.Split(','); // ["전사", "마법사", "도적"]

string joined = string.Join(" ➔ ", jobs); // "전사 ➔ 마법사 ➔ 도적"
```

> **팁: 빈 조각 버리기 (`RemoveEmptyEntries`)**\
> `"A,B,,C"` 처럼 쉼표가 연달아 있으면 빈 조각(`""`)이 생깁니다. 옵션을 주어 깔끔하게 버릴 수 있습니다.\
> `csvData.Split(',', StringSplitOptions.RemoveEmptyEntries);`

### 3.4 메서드 체이닝 (Method Chaining)
`string` 메서드는 대부분 `string`을 반환하므로 사슬처럼 기차놀이가 가능합니다.
```csharp
// 양 끝 공백 제거 -> 소문자 변환 -> 띄어쓰기를 하이픈으로 변경
string result = userInput.Trim().ToLower().Replace(' ', '-'); 
```

## 4. 흔한 실수와 방어 코드

### ❌ 흔한 실수 1: 반환값 무시 (아무 일도 안 일어남)
```csharp
string message = "This is a bad word.";
message.Replace("bad", "good"); // 반환된 결과물을 허공에 날려버림

Console.WriteLine(message); // 원본은 불변이므로 "This is a bad word." 출력
```

### ❌ 흔한 실수 2: `IndexOf`의 `-1` 예외 처리 누락
```csharp
string text = "Hello";
int pos = text.IndexOf("World");     // "World"가 없으므로 pos에는 -1이 들어감
string sub = text.Substring(pos, 3); // ArgumentOutOfRangeException! (인덱스가 -1일 순 없음)
```

### ⭕ 올바른 방어 패턴 적용 (After)
```csharp
// 1. 반환값을 반드시 덮어씌운다. (s = s.Method() 패턴)
string message = "This is a bad word.";
message = message.Replace("bad", "good"); 

// 2. IndexOf는 무조건 -1 (실패)인지 검사한다.
string text = "Hello World";
int pos = text.IndexOf("World");
if (pos != -1) 
{
    Console.WriteLine(text.Substring(pos, 5)); 
}
```

## 5. 실전 활용 예시 (게임 데이터 필터링)
아이템 데이터 문자열을 파싱(`Split`)하고, 가공하여, 다시 결합(`Join`)하는 가장 표준적인 흐름입니다.

```csharp
public class DataParser
{
    // 입력 예시: "검:1500,방패:3000,포션:100,투구:2500"
    public void ProcessItemData(string itemStr)
    {
        // 1. 아이템 단위로 분리 (쉼표 기준)
        string[] items = itemStr.Split(',');

        var expensiveItems = new List<string>();
        
        // 2. 각 아이템 문자열 가공
        foreach (string item in items)
        {
            string[] parts = item.Split(':'); // 이름과 가격 분리
            if (parts.Length != 2) continue;  // 데이터 오염 방어

            string name = parts[0];
            if (!int.TryParse(parts[1], out int price)) continue; // 안전한 파싱

            // 가격 2000원 이상만 수집
            if (price >= 2000)
                expensiveItems.Add($"{name}({price}G)");
        }

        // 3. 리스트를 다시 하나의 깔끔한 텍스트로 결합
        string result = string.Join(" | ", expensiveItems);
        Console.WriteLine($"고가 아이템 ➔ {result}");
    }
}

// 결과: 고가 아이템 ➔ 방패(3000G) | 투구(2500G)
```

## 6. Unity 실무: 완벽한 CSV 데이터 파싱

Unity에서 기획자가 넘겨준 CSV나 텍스트 에셋을 읽어올 때, `Split`과 `Trim`은 핵심 무기가 됩니다.\
특히 Windows 환경에서는 줄바꿈이 `\r\n`으로 들어오기 때문에, 찌꺼기 `\r`을 제거하는 팁이 포함되어 있습니다.

```csharp
using UnityEngine;
using System.Collections.Generic;

[System.Serializable]
public class ItemData { public int Id, Level, Price; public string Name; }

public class ItemDatabase : MonoBehaviour
{
    [SerializeField] private TextAsset _itemCsv; // Unity 인스펙터에서 CSV 드래그 앤 드롭
    public List<ItemData> Items = new List<ItemData>();

    void Start()
    {
        // 꿀팁: 윈도우의 \r\n과 맥의 \n을 모두 대비하고, 빈 줄은 깔끔하게 무시합니다
        string[] lines = _itemCsv.text.Split(new[] { '\r', '\n' }, System.StringSplitOptions.RemoveEmptyEntries);

        foreach (string line in lines)
        {
            // 쉼표로 열(Column) 분리
            string[] columns = line.Split(',');
            if (columns.Length < 4) continue; // 열 개수 방어 코드

            Items.Add(new ItemData
            {
                Id = int.Parse(columns[0]),
                Name = columns[1].Trim(), // 혹시 모를 앞뒤 공백 제거
                Level = int.Parse(columns[2]),
                Price = int.Parse(columns[3])
            });
        }

        Debug.Log($"[시스템] {Items.Count}개의 아이템 데이터 로드 완료!");
    }
}
```
> **Unity 최적화 주의사항**:\
> 이런 문자열 쪼개기(`Split`) 작업은 메모리 할당(힙에 문자열 조각 생성)을 엄청나게 유발합니다.\
> 따라서 위 코드처럼 `Start()`나 로딩 씬에서 **딱 한 번만** 실행해서 데이터를 `Class/Struct`로 만들어두고, 런타임(게임 플레이 중)에는 파싱 작업을 절대 피해야 합니다.

## 7. 실습 문제 및 복습

**Q1. `Replace()` 메서드는 원본을 직접 수정할까요? 이유와 함께 설명하세요.**
> 수정하지 않습니다. `string`은 한 번 만들어지면 변하지 않는 **불변(Immutable)** 객체이기 때문입니다. `Replace`를 비롯한 모든 수정 메서드는 원본을 보존하고 수정된 내용이 담긴 '새로운 문자열 객체'를 힙에 생성하여 반환합니다.

**Q2. 파일명 `" MyReport.docx "`을 (1) 양끝 공백을 제거하고 (2) 소문자로 변환하여 (3) `.docx`로 끝나는지 판별하는 코드를 메서드 체이닝으로 작성하세요.**
```csharp
string raw = " MyReport.docx "; 
// 체이닝으로 찌꺼기를 없애고 포맷을 통일한 뒤 검사합니다.
bool isDocx = raw.Trim().ToLower().EndsWith(".docx"); 
Console.WriteLine($"Word 문서 맞나요? : {isDocx}");
```

**Q3. `Split`과 `string.Join`의 관계는 데이터 직렬화/역직렬화 관점에서 어떻게 활용되나요?**
> * **`string.Join` (직렬화)**: 흩어져 있는 객체나 배열을 쉼표(`,`) 등의 구분자로 합쳐서, 세이브 파일(TXT, CSV)이나 서버로 전송할 수 있는 **한 줄의 텍스트**로 압축합니다.
> * **`Split` (역직렬화)**: 뭉쳐진 텍스트를 다시 구분자로 잘라내어, 프로그램이 읽고 계산할 수 있는 **배열(`string[]`) 데이터**로 복원합니다.
    > 단순한 세이브 데이터 저장 및 로드, 설정 파일 관리에 가장 강력한 무기입니다.

## 8. 주의사항 및 안전 습관

* **`s = s.Method()` 패턴을 외워라**: 문자열 변환 메서드는 허공에 호출만 하면 아무 일도 일어나지 않습니다. 반드시 결과를 변수에 덮어씌우세요.
* **`IndexOf`는 `-1` 검사가 국룰이다**: 찾고자 하는 문자가 없을 때 반환되는 `-1`을 그대로 `Substring` 등에 넣으면 게임이 터집니다. 반드시 `if (pos != -1)` 방어벽을 세우세요.
* **사용자 입력은 `Trim()`부터 해라**: 유저가 아이디를 입력할 때 뒤에 띄어쓰기를 실수로 넣는 경우가 아주 많습니다. 비교하거나 저장하기 전에 항상 `Trim()`으로 청소하는 습관을 들이세요.
