# [Collection_Generic_Deligate] 1. 1D·2D 배열 활용 (Array in Practice)

## 1. 과제 개요
### 1.1 무엇을 하나요?
배열이 무엇인지는 08. 배열과 09. 다차원 배열에서 이미 배웠습니다. 이 문서는 그 문법을 다시 설명하지 않습니다. 배열 하나를 놓고 실제로 하고 싶어지는 일들을 직접 구현해 보는 자리입니다.

문항은 네 묶음입니다. 묶음마다 손에 남는 것이 다릅니다.

| 묶음             | 문항      | 무엇을 묻나                                             | 복습할 챕터      | 예상  |

세 번째 묶음이 이 문서의 마루입니다. 병합 · 삭제 · 삽입은 셋 다 "새 배열을 만들어 옮겨 담기" 라는 같은 동작으로 풀립니다. 왜 그래야만 하는지를 손으로 겪고 나면 다음 챕터의 List<T> 가 문법이 아니라 답으로 읽힙니다.

> 이 문서 전체에서 LINQ 를 쓰지 않습니다\
> Max() · Min() · Distinct() · Where() · ToArray() 같은 확장 메서드는 이 문서의 모든 문항에서 금지입니다. 한 줄로 끝나 버리면 배열이 무엇을 못 하는지가 보이지 않습니다. 쓸 수 있는 것은 반복문과 Array · string 의 정적 메서드까지입니다. LINQ 는 코스 4 「04. 컬렉션과 LINQ」에서 제대로 다룹니다.

## 2. 과제
### 2.1 묶음 1 ㅡ 순회와 누적 (15분)
세 문항의 뼈대는 모두 같습니다. 바깥에 결과를 담을 변수를 하나 두고, 배열을 한 바퀴 돌면서 그 변수를 갱신합니다. 달라지는 것은 변수의 초기값과 갱신 조건뿐입니다.

### Q1. 값이 처음 나오는 위치 (Q1_IndexOf)
정수 배열 numbers 에서 target 과 같은 값이 처음 나오는 인덱스를 반환하세요. 없으면 -1 을 반환합니다.

| 입력                  | target | 기대값 |
|:--------------------|:-------|:----|
| {10, 25, 30, 7, 42} | 30     | 2   |
| {10, 25, 30, 7, 42} | 10     | 0   |
| {10, 25, 30, 7, 42} | 99     | -1  |
| {7, 7, 7}           | 7      | 0   |
| 빈 배열                | 5      | -1  |
> 힌트: 찾았으면 더 돌 이유가 없습니다. 반복문 안에서 바로 반환하면 found 같은 bool 변수가 필요 없어집니다.

### Q2. 최솟값과 최댓값을 한 번에 (Q2_MinMax)
정수 배열 numbers 의 최솟값과 최댓값을 길이 2인 배열 { 최솟값, 최댓값 } 으로 반환하세요. 배열의 길이는 항상 1 이상입니다.

| 입력                  | 기대값      | Join(결과) |
|:--------------------|:---------|:---------|
| {10, 25, 30, 7, 42} | {7, 42}  | "7,42"   |
| {-5, -1, -9}        | {-9, -1} | "-9, -1" |
| {42}                | {42, 42} | "42, 42" |
| {0, 0, 0}           | {0, 0}   | "0, 0"    |
힌트: 초기값을 0 으로 두면 {-5, -1, -9} 에서 최댓값이 0 으로 나옵니다. 배열 안에 없는 값을 초기값으로 삼지 않는 것이 요령입니다.

### Q3. 평균 미만인 값의 개수 (Q3_CountBelowAverage)
정수 배열 numbers 의 평균을 구한 뒤, 평균보다 작은 값이 몇 개인지 반환하세요. 배열이 비어 있으면 0 을 반환합니다.
* 평균과 정확히 같은 값은 세지 않습니다. 
* 평균은 정수 나눗셈이 아니라 실수로 계산합니다.

| 입력                  | 평균        | 기대값 |
|:--------------------|:----------|:----|
| {10, 25, 30, 7, 42} | 22.8      | 2   |
| {1, 2, 3, 4}        | 2.5       | 2   |
| {100, 200, 301}     | 200.33... | 2   |
| {5, 5, 5}           | 5         | 0   |
| {10}                | 10        | 0   |
| 빈 배열                | ㅡ         | 0   |
힌트: {100, 200, 301} 이 함정입니다. 합 601 을 int 끼리 나누면 평균이 200 으로 잘려 200 이 세어지지 않습니다. 그리고 평균을 알려면 배열을 두 번 돌아야 합니다. 한 번은 합을 구하러, 한 번은 세러 갑니다.

### 2.2 묶음 2 — Array · string 정적 메서드 (15분)
묶음 1 을 손으로 돌려 봤으니, 이제 Array 클래스가 미리 만들어 둔 것들을 씁니다. 다만 원본을 바꾸는 메서드가 섞여 있어서, 그냥 부르면 호출한 쪽의 배열까지 바뀝니다. 이 묶음의 진짜 주제가 그것입니다.

### Q4. 원본을 지키는 정렬 (Q4_SortedCopy)
정수 배열 numbers 를 오름차순으로 정렬한 새 배열을 반환하세요. 넘겨받은 배열은 그대로여야 합니다.

| 입력                  | Join(결과)            |
|:--------------------|:--------------------|
| {10, 25, 30, 7, 42} | "7, 10, 25, 30, 42" |
| {3, 1, 2}           | "1, 2, 3"           |
| {5}                 | "5"                 |
| 빈 배열                | ""                  |
원본이 지켜졌는지도 함께 채점해 보세요. 같은 배열 변수를 만들어 두고 함수를 부른 뒤에 확인합니다.
```csharp
int[] source = { 10, 25, 30, 7, 42 };
//Check("Q4-0", Join(Q4_SortedCopy(source)), "7,10,25,30,42");
//Check("Q4-원본", Join(source), "10,25,30,7,42");                          // 원본은 그대로여야 한다
```
힌트: Array.Sort 는 결과를 돌려주지 않고 넘겨받은 배열 자체를 정렬합니다. 배열은 참조로 전달되므로, 복사 없이 부르면 원본이 함께 정렬됩니다.

### Q5. 중복된 값 모으기 (Q5_Duplicates)
정수 배열 numbers 에서 두 번 이상 나온 값을 처음 나온 순서대로 한 번씩만 담은 새 배열을 반환하세요.
* Distinct() 를 비롯한 LINQ 는 쓰지 않습니다.
* 중복이 없으면 길이 0 인 배열을 반환합니다.

| 입력                    | Join(결과) |
|:----------------------|:---------|
| {1, 2, 3, 2, 4, 5, 4} | "2, 4"   |
| {1, 2, 3}             | ""       |
| {7, 7, 7}             | "7"      |
| {5, 5, 5, 5, 3, 3}    | "5, 3"   |
| 빈 배열                  | ""       |
힌트: {7, 7, 7} 에서 7 이 한 번만 나와야 한다는 조건이 까다롭습니다. "내 앞쪽에 나와 동일한 값이 있는가" 를 함께 검사하면, 그 값이 처음 등장한 자리에서만 결과에 담기게 만들 수 있습니다.

### Q6. 역순으로 이어 붙이기 (Q6_JoinReversed)
문자열 배열 words 를 역순으로 > 로 이어 붙인 문자열 하나를 반환하세요. 넘겨받은 배열은 그대로여야 합니다.

| 입력                            | 기대값                       |
|:------------------------------|:--------------------------|
| {"apple", "banana", "cherry"} | "cherry > banana > apple" |
| {"only"}                      | "only"                    |
| 빈 배열                          | ""                        |
힌트: 구분자를 사이에만 넣는 일은 직접 하면 마지막 하나가 늘 남습니다. string.Join 이 그 처리를 대신해 줍니다. 역순은 Array.Reverse 로 만들 수 있지만, 이 메서드 역시 원본을 뒤집는다는 점을 잊지 마세요.

### 2.3 묶음 3 — 새 배열로 옮겨 담기 (20분)
배열에는 Add 도 Remove 도 Insert 도 없습니다. 길이가 바뀌는 일은 전부 "새 배열을 만들고 옮겨 담기" 로만 됩니다. 세 문항은 같은 동작의 세 얼굴입니다. 풀고 나면 셋이 한 가지 일이었다는 것이 보입니다.

### Q7. 두 배열 합치기 (Q7_Merge)
정수 배열 둘을 first 뒤에 second 가 오도록 이어 붙인 새 배열을 반환하세요.

| first     | second    | Join(결과)       |
|:----------|:----------|:---------------|
| {1, 2, 3} | {4, 5, 6} | "1,2,3,4,5,6"  |
| {1}       | 빈 배열      | "1"            |
| 빈 배열      | {1}       | "1"            |
| 빈 배열      | 빈 배열      | ""              |
힌트: 새 배열의 길이는 두 길이의 합입니다. 뒤쪽 배열을 채울 때 쓰기 위치가 first.Length 만큼 밀린다는 점만 맞추면 끝납니다.

### Q8. 값 하나 지우기 (Q8_RemoveFirst)
정수 배열 numbers 에서 target 과 같은 값이 처음 나오는 것 하나만 제거한 새 배열을 반환하세요. target 이 없으면 내용이 같은 새 배열을 반환합니다.

| 입력              | target | Join(결과)    |
|:----------------|:-------|:------------|
| {1, 2, 3, 4, 5} | 3      | "1,2,4,5"   |
| {1, 2, 3, 4, 5} | 9      | "1,2,3,4,5" |
| {7, 7, 7}       | 7      | "7, 7"      |
| {5}             | 5      | ""          |
| 빈 배열            | 5      | ""           |
힌트: 새 배열의 길이가 numbers.Length - 1 인지 numbers.Length 인지는 지울 것이 있느냐에 달려 있습니다. 지울 위치를 먼저 찾아 두면(Q1 을 그대로 쓸 수 있습니다) 길이를 미리 정할 수 있습니다.

### Q9. 가운데에 끼워 넣기 (Q9_Insert)
정수 배열 numbers 의 index 위치에 value 가 오도록 끼워 넣은 새 배열을 반환하세요. index 는 0 이상 numbers.Length 이하이며, numbers.Length 이면 맨 뒤에 붙입니다.

| 입력           | index | value | Join(결과)    |
|:-------------|:------|:------|:------------|
| {1, 2, 4, 5} | 2     | 3     | "1,2,3,4,5" |

| {1, 2, 3}    | 3     | 4     | "1,2,3,4"   |
| 빈 배열         | 0     | 1     | "1"          |
힌트: 끼워 넣는 자리 앞쪽은 위치가 그대로이고, 뒤쪽은 한 칸씩 밀립니다. 두 구간을 나눠 옮기면 인덱스 계산이 단순해집니다.

### 2.4 묶음 4 — 2차원 배열 순회 (10분)
2차원 배열은 행과 열이 있지만, 메모리에는 한 줄로 놓여 있습니다. 두 문항이 그 사실을 양쪽에서 확인합니다.

### Q10. 행별 합계 (Q10_RowSums)
2차원 정수 배열 board 의 각 행의 합을 담은 1차원 배열을 반환하세요. 결과의 길이는 행의 개수와 같습니다.

| 입력                            | 크기    | Join(결과)  |
|:------------------------------|:------|:----------|
| { {1,2,3}, {4,5,6} }          | 2행 3열 | "6,15"    |
| { {1,2,3}, {4,5,6}, {7,8,9} } | 3행 3열 | "6,15,24" |
| { {0,0}, {0,0} }              | 2행 2열 | "0,0"     |
| { {5} }                       | 1행 1열 | "5"        |
힌트: 행 개수는 board.GetLength(0), 열 개수는 board.GetLength(1) 입니다. board.Length 는 전체 칸 수(2행 3열이면 6)라서 행 개수로 쓸 수 없습니다.

### Q11. foreach 는 어떤 순서로 도나요? (Q11_Flatten)
2차원 배열을 foreach 로 돌면 행과 열의 구분 없이 값이 하나씩 일렬로 나옵니다. 그 순서를 눈으로 확인하는 문항입니다. foreach 로 배열을 돌면서 각 값을 "(행,열)=값" 형태의 문자열로 만들어 나온 순서 그대로 string[] 에 담아 반환하세요.
* 반복 변수에서는 행·열 번호를 알 수 없습니다. 몇 번째로 나왔는지를 세어 행·열로 환산해야 합니다. 
* 중첩 for 로 풀면 이 문항의 요점이 사라집니다. foreach 로 구현하세요.

| 입력                   | 크기    | Join(결과)                                          |
|:---------------------|:------|:--------------------------------------------------|
| { {1,2,3}, {4,5,6} } | 2행 3열 | "(0,0)=1,(0,1)=2,(0,2)=3,(1,0)=4,(1,1)=5,(1,2)=6" |
| { {7,8}, {9,10} }    | 2행 2열 | "(0,0)=7,(0,1)=8,(1,0)=9,(1,1)=10"                |
| { {5} }              | 1행 1열 | "(0,0)=5"                                         |
힌트: 몇 번째로 나왔는지를 index 라 하고 열 개수를 columns 라 하면, 몫과 나머지가 그대로 행과 열입니다. 03. 연산자에서 거스름돈을 500원짜리 몇 개와 남는 금액으로 쪼개던 / 와 % 의 짝이 여기서 다시 나옵니다.

### 4.3 배열은 언제 쓰고 언제 놓나요 ?
이 문서에서 겪은 것을 그대로 판단 기준으로 옮기면 이렇게 됩니다.

| 이럴 때 배열이 맞습니다                          | 이럴 때는 배열이 버겁습니다        |
|:---------------------------------------|:-----------------------|
| 개수가 처음부터 정해져 있습니다 (요일 7칸, 인벤토리 슬롯 20칸) | 실행 중에 개수가 늘거나 줍니다      |
| 위치를 알고 그 자리를 바로 읽고 씁니다                 | 중간에 끼워 넣거나 빼는 일이 잦습니다  |
| 메모리를 한 덩어리로 아껴 써야 합니다                  | 매번 전체를 옮겨 담는 비용이 아깝습니다 |
오른쪽 칸이 바로 묶음 3 에서 손으로 겪은 것입니다. 값 하나를 넣고 빼는 데 배열 전체를 새로 만들어 옮겨 담아야 했고, 그 코드는 세 문항 모두 똑같이 생겼습니다. 같은 코드를 세 번 썼다면, 누군가 이미 그것을 만들어 두었을 가능성이 큽니다.
