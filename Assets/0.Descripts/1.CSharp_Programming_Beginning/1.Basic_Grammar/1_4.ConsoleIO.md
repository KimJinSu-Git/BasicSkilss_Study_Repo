# [C# 기초] 4. 콘솔 입출력 (Console I/O)

## 1. 콘솔 입출력이란?
콘솔 입출력(Console I/O)은 프로그램과 사용자가 텍스트를 통해 서로 '대화'하는 가장 기본적인 방법입니다. 콘솔(검은 화면의 명령 프롬프트나 터미널)에 정보를 표시하거나 키보드 입력을 받는 모든 활동을 말합니다.

> **직관적인 비유 : 쪽지 교환 창구**\
> 프로그램과 사용자 사이에 놓인 은행 창구라고 생각해 보세요.
> * **출력 (Output)** : 프로그램이 사용자에게 안내문이나 질문이 적힌 쪽지를 창구 너머로 건네주는 것 (`Console.WriteLine`)
> * **입력 (Input)** : 사용자가 키보드로 답변을 작성해 창구를 통해 프로그램에 전달하는 것 (`Console.ReadLine`)

**왜 필요한가?**
입력을 받지 못하는 프로그램은 미리 정해진 동작만 반복하는 비디오테이프와 같습니다.\
사용자의 데이터를 받고 그에 맞춰 결과를 처리해 보여주어야 비로소 게임, 계산기, 로그인 시스템 같은 상호작용(Interaction)이 가능한 소프트웨어가 됩니다.

---

## 2. 핵심 요약

| 개념 | 한 줄 설명 |
| :--- | :--- |
| **`Console.WriteLine()`** | 콘솔에 글자를 출력하고 **다음 줄로 넘어감** (줄바꿈 O) |
| **`Console.Write()`** | 콘솔에 글자를 출력하고 **그 줄에 머무름** (질문할 때 유용) |
| **`Console.ReadLine()`** | 사용자가 Enter를 칠 때까지 기다렸다가, **입력값을 무조건 `string`으로 반환** |
| **파싱 (Parsing)** | 문자열(string)을 숫자(int, float) 등 다른 자료형으로 변환하는 작업 |
| **문자열 보간 (`$"{}"`)** | 문자열 안에 변수를 깔끔하게 끼워 넣는 현대적인 C# 문법 |
| **이스케이프 시퀀스 (`\n`)**| 문자열 안에서 줄바꿈(`\n`)이나 탭(`\t`)을 표현하는 특수 기호 |

## 3. 프로그램과 사용자의 대화 순서 (데이터 흐름)

프로그램이 나이를 물어보고 대답을 출력하기까지의 과정입니다. `ReadLine`은 항상 `문자열`(string)을 반환하므로 숫자로 계산하려면 반드시 `형변환`(Parsing)이 필요합니다.

1. **[프로그램]** `Console.Write("나이?");` ➔ (질문 쪽지 건넴)
2. **[사용자]** `25` 입력 후 Enter ➔ (답변 쪽지 제출)
3. **[프로그램]** `ReadLine()`이 `"25"`(문자열)로 읽어옴
4. **[프로그램]** `int.TryParse("25")` ➔ 진짜 숫자 `25`로 변환 (파싱)
5. **[프로그램]** `Console.WriteLine($"{age}살이군요!");` ➔ (최종 결과 출력)

## 4. 안전한 형변환 : Parse vs TryParse

사용자의 입력은 항상 예측 불가능합니다. 숫자를 쓰라고 해도 "이십오"라고 치는 것이 사용자입니다.

```csharp
string input = Console.ReadLine();

// ❌ 직접 변환 (위험)
// 사용자가 "abc"를 입력하면 FormatException 에러가 터지며 프로그램이 즉시 강제 종료됩니다.
int badNumber = int.Parse(input); 

// ⭕ 안전한 변환 (실무 권장)
// 성공하면 true를 반환하고 값을 number에 쏙 넣어줍니다. 실패하면 false를 반환하고 프로그램은 죽지 않습니다.
bool isSuccess = int.TryParse(input, out int number); 
```

> **`out` 키워드가 뭔가요?**\
> C#의 메서드는 기본적으로 반환값(`return`)을 딱 1개만 가질 수 있습니다.\
> `TryParse`는 1) 변환 성공 여부(`bool`)와 2) 변환된 숫자(`int`) 두 가지를 줘야 합니다. 그래서 반환값으로는 `bool`을 던져주고, 숫자는 매개변수 쪽에 `out`을 달아 "여기에 담아줄게!" 라고 하는 약속입니다.

## 5. 코드로 보는 콘솔 입출력

### 5.1 기본 예시와 문자열 보간
```csharp
// 입력 유도 (Write 사용 - 줄바꿈 없이 커서가 옆에서 깜빡임)
Console.Write("당신의 이름은? ");
string userName = Console.ReadLine();

Console.Write("몇 년도 출생? ");
string birthYearStr = Console.ReadLine();

// 파싱 및 계산
int birthYear = int.Parse(birthYearStr); // (예제를 위해 일단 Parse 사용)
int age = 2026 - birthYear;

// 문자열 보간($)과 이스케이프 시퀀스(\n) 활용
Console.WriteLine($"\n안녕하세요, {userName}님!");
Console.WriteLine($"당신은 {birthYear}년생, 2026년 기준 약 {age}세입니다.");
```

### 5.2 올바른 예외 처리 패턴 (실무 표준)
```csharp
Console.Write("숫자를 입력하세요: ");
string input = Console.ReadLine();

// if 조건문 안에서 변환 시도와 성공 여부 검사를 동시에 처리하는 세련된 패턴
if (int.TryParse(input, out int number))
{
    Console.WriteLine($"입력한 숫자에 10을 더하면 {number + 10} 입니다.");
}
else
{
    // 사용자가 문자를 입력했을 때의 방어 코드
    Console.WriteLine("[오류] 숫자가 아닙니다. 다시 시도하세요.");
}
```

## 6. 활용 예시 (게임 도메인)

로그인 시스템이나 콘솔 RPG 전투에서 자주 사용하는 패턴입니다.

```csharp
string savedId = "admin";
string savedPw = "1234";

Console.WriteLine("===  게임 서버 로그인 ===");

Console.Write("아이디: ");
string inputId = Console.ReadLine();

Console.Write("비밀번호: ");
string inputPw = Console.ReadLine();

// && (AND) 연산자를 사용해 두 조건이 모두 맞을 때만 로그인 성공
if (inputId == savedId && inputPw == savedPw)
{
    // \n 을 문자열 맨 앞에 쓰면 빈 줄을 하나 띄우고 출력합니다.
    Console.WriteLine($"\n접속 성공! {inputId}님, 환영합니다.");
}
else
{
    Console.WriteLine("\n[System] 로그인 실패. 아이디나 비밀번호를 확인하세요.");
}
```

## 7. Unity에서는 어떻게 쓸까?

Unity는 검은 콘솔 창 대신 화려한 그래픽 UI(User Interface)를 사용하므로 창구의 생김새가 달라집니다. 하지만 '데이터를 주고받는 본질'은 완전히 같습니다.

```csharp
using UnityEngine;
using TMPro; // 텍스트 UI를 다루기 위한 네임스페이스

public class PlayerInput : MonoBehaviour
{
    [SerializeField] private TMP_InputField _nameInputField; // 입력 창구 (ReadLine 역할)
    [SerializeField] private TMP_Text _greetingText;         // 출력 창구 (WriteLine 역할)

    // UI 버튼을 클릭했을 때 실행되는 메서드
    public void OnSubmitButtonClicked()
    {
        // 입력: 콘솔의 ReadLine() 대신 UI 필드의 text 속성을 읽어옵니다.
        string playerName = _nameInputField.text;     
        
        // 출력: 콘솔의 WriteLine() 대신 UI 텍스트의 text 속성을 바꿔치기합니다.
        _greetingText.text = $"반갑습니다, 용사 {playerName} 님!";

        // 개발자용 확인: Unity 콘솔창에 로그 찍기
        Debug.Log($"[시스템] 새로운 플레이어 접속: {playerName}");
    }
}
```
> **핵심 포인트:** Unity에서는 `Console.ReadLine()`을 절대 쓰지 않습니다. 게임은 1초에 60번씩 화면을 그려야 하는데, `ReadLine`을 쓰면 사용자가 엔터를 칠 때까지 **게임이 완전히 멈춰버리기 때문**입니다. 대신 이벤트(버튼 클릭 등)를 통해 입력을 받습니다.

## 8. 실습 문제 및 복습

**Q1. `Console.WriteLine()`과 `Console.Write()`의 가장 큰 차이는?**
> `WriteLine`은 출력 후 다음 줄로 넘어갑니다(엔터 효과). `Write`는 출력 후 커서가 같은 줄에 머뭅니다. 그래서 사용자에게 입력을 받기 직전 힌트나 질문("이름을 입력하세요: ")을 출력할 때 주로 `Write`를 사용합니다.

**Q2. `Console.ReadLine()`이 반환하는 데이터 타입은? 숫자를 계산하려면 어떤 과정이 필요한가?**
> 항상 `string`(문자열)을 반환합니다. 따라서 수학 계산을 하려면 문자열을 숫자로 바꿔주는 파싱(`int.Parse` 또는 `int.TryParse`) 과정이 반드시 필요합니다.

**Q3. `int.Parse()`가 위험한 이유를 설명하고, 아래 코드를 `TryParse`를 사용해 안전하게 수정하세요.**
```csharp
// [위험한 원본 코드]
Console.Write("상품 가격: ");
int price = int.Parse(Console.ReadLine()); 
// 이유: 사용자가 "공짜"라고 한글을 입력하면 프로그램이 에러를 뿜으며 즉시 꺼집니다.
```
```csharp
// [안전하게 수정된 코드]
Console.Write("상품 가격: ");
if (!int.TryParse(Console.ReadLine(), out int price))
{
    // ! (NOT 연산자)를 붙여서 변환에 실패했을 때 방어
    Console.WriteLine("잘못된 입력입니다. 숫자로만 입력해주세요.");
    return; // 메서드 종료
}
Console.WriteLine($"입력된 가격: {price}원");
```

## 9. 실무 주의사항 및 팁

* **사용자의 입력은 항상 의심하라!** : `int.Parse`는 되도록 쓰지 마세요. 사용자의 오타 한 번에 프로그램이 죽는 것은 최악의 사용자 경험(UX)입니다. 항상 `TryParse`를 사용하는 습관을 들이세요.
* **출력 포맷팅 기법**:
    * 소수점 자르기: `Console.WriteLine($"속도: {speed:F2}");` (소수점 둘째 자리까지 출력)
    * 돈 표시: `Console.WriteLine($"금액: {price:C}");` (화폐 단위 ₩ 표시와 천 단위 콤마)
* **`Console.Clear()`** : 콘솔의 이전 글자들을 싹 지워줍니다. 콘솔로 게임을 만들 때 매 프레임마다 화면을 지우고 다시 그리는 용도로 아주 유용합니다.
