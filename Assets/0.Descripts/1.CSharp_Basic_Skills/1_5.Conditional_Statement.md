# [C# 기초] 5. 조건문 (Conditional Statement)

## 1. 조건문이란?
조건문(Conditional Statement)은 프로그램의 실행 흐름에 갈림길을 만들어주는 문법입니다. 주어진 조건의 참(`true`)/거짓(`false`)에 따라 정해진 코드 블록 중 하나를 선택해 실행시킵니다.

> **직관적인 비유 : 내비게이션의 경로 안내**
> * **현재 위치 (상태)** : 변수에 저장된 값 (`int score = 85;`)
> * **교차로 (조건)** : 갈림길에서의 판단 (`if (score >= 80)`)
> * **경로 안내 (평가)** : "85는 80 이상이므로 우회전('B 학점' 경로) 하세요!"
> * **선택된 길** : B 학점을 부여하는 코드만 실행되고, 나머지 길(A, C, F학점)은 무시됩니다.

**왜 필요한가?**\
조건문이 없으면 프로그램은 외길을 가듯 정해진 순서로만 동작합니다. "체력이 0 이하면 게임 오버", "관리자 계정이면 설정 메뉴 표시" 같은 상황별 분기를 만들어야 비로소 지능적이고 유연한 프로그램이 탄생합니다.

---

## 2. 핵심 요약

| 키워드 | 한 줄 설명 |
| :--- | :--- |
| `if` | 단일 조건. `true`일 때만 내부 코드를 실행 |
| `if-else` | 양자택일. `true`일 때와 `false`일 때 각각 다른 코드를 실행 |
| `if-else if-else`| 다중 분기. 여러 조건 중 윗줄부터 검사하여 **처음으로 일치하는 하나만** 실행 |
| `switch` | 하나의 변수를 여러 상수 값(또는 패턴)과 비교할 때 사용 |
| `break` | `switch`의 각 `case` 끝에 필수로 작성 (탈출구 역할) |
| `default` | `switch`에서 어떤 `case`와도 일치하지 않을 때 실행 (선택 사항) |

## 3. 세부 개념 및 실무 팁

### 3.1 `if` 계열: 가장 유연한 도구
비교 연산자와 논리 연산자(`&&`, `||`)를 자유롭게 조합할 수 있어 범위 비교(예: 80~89점)에 특히 유리합니다.

**실무 주의: 조건 순서의 함정**
`if-else if`는 위에서부터 차례대로 검사하다가 **첫 번째 `true`를 만나면 나머지 조건은 쳐다보지도 않고 종료**합니다.
따라서 범위가 좁은 조건(달성하기 어려운 조건)부터 먼저 배치해야 합니다.

### 3.2 조건문 안의 변수 수명 (Scope) 
중괄호 `{ }` 안에서 새로 선언한 변수는 중괄호가 끝날 때 메모리에서 삭제됩니다.
조건에 따라 값을 결정해야 한다면, **변수 선언은 조건문 밖에서** 해야 합니다.
```csharp
// ❌ 잘못된 사용
if (isCritical) { int damage = 100; }
else { int damage = 50; }
// Console.WriteLine(damage); -> 에러! damage 변수는 이미 사라졌음

// ⭕ 올바른 사용
int damage = 50; // 밖에서 선언 및 기본값 초기화
if (isCritical) { damage = 100; }
```

## 4. 코드로 보는 조건문

### 4.1 `if-else if-else` 올바른 순서 배치
```csharp
int age = 25;

// [올바른 순서] 좁은 범위(높은 기준)부터 검사해야 안전합니다.
if (age >= 20)                     
{
    Console.WriteLine("성인 요금");
}
else if (age >= 8) // 위에서 20 이상은 걸러졌으므로, 사실상 8~19세를 의미함
{
    Console.WriteLine("청소년 요금");
}
else
{
    Console.WriteLine("어린이 요금");
}
```

### 4.2 모던 C#의 `switch` (패턴 매칭 적용)
최신 C#에서는 `switch`문이 진화하여 단순 값 비교를 넘어 논리 연산까지 지원합니다.
```csharp
Console.Write("메뉴 선택(1~4): ");
string input = Console.ReadLine();

switch (input)
{
    case "1":
        Console.WriteLine("새 게임을 시작합니다.");
        break;
    case "2":
    case "3": // 이렇게 비워두면 2나 3일 때 아래 코드가 실행됨 (fall-through)
        Console.WriteLine("저장/설정 메뉴입니다.");
        break;
    default:
        Console.WriteLine("잘못된 입력입니다.");
        break;
}
```

## 5. 활용 예시 (Unity 게임 도메인)

Unity에서 캐릭터의 상태(State)를 관리할 때는 **`enum` + `switch` 조합**이 실무 표준 패턴입니다. `if`문으로 떡칠하는 것보다 훨씬 깔끔하고 관리가 쉽습니다.

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    // 캐릭터가 가질 수 있는 상태를 명시적으로 정의
    public enum State { Idle, Running, Jumping, Dead }
    public State currentState = State.Idle;

    void Update()
    {
        // 현재 상태에 따라 1초에 60번씩 다른 행동을 처리
        switch (currentState)
        {
            case State.Idle:
                if (Input.GetKeyDown(KeyCode.Space))
                    currentState = State.Jumping; // 스페이스바 누르면 점프 상태로 전환
                break;

            case State.Running:
                if (Input.GetKeyUp(KeyCode.LeftShift))
                    currentState = State.Idle;
                break;

            case State.Jumping:
                // 점프 물리 처리... 착지하면 다시 State.Idle로 전환
                break;

            case State.Dead:
                return; // 사망 상태면 아래 코드를 무시하고 입력 차단
        }
    }
}
```

## 6. 실습 문제 및 복습

**Q1. `if-else if`와 `switch`는 각각 어떤 상황에 더 적합한가요?**
> * `if-else if`: 점수 범위, 복잡한 논리 조합(`&&`, `||`) 등 **범위나 조건이 복합적일 때** 유리합니다.
> * `switch`: 메뉴 번호, 캐릭터 상태(`enum`), 요일 등 **정확한 상수 값 매칭**이 필요할 때 가독성이 압도적으로 좋습니다.

**Q2. 사용자에게 점수(0~100)를 입력받아 학점을 출력하는 프로그램을 작성하세요.**
```csharp
Console.Write("점수: ");
if (int.TryParse(Console.ReadLine(), out int score)) // 안전한 파싱 습관!
{
    string grade; // 변수는 조건문 밖에서 선언!
    
    if (score >= 90) grade = "A";
    else if (score >= 80) grade = "B";
    else if (score >= 70) grade = "C";
    else if (score >= 60) grade = "D";
    else grade = "F";
    
    Console.WriteLine($"당신의 학점은 {grade}입니다.");
}
else
{
    Console.WriteLine("잘못된 입력입니다. 숫자를 입력하세요.");
}
```

**Q3. 아래 코드를 `switch`로 다시 작성하세요.**
```csharp
// [원본 코드]
int dayOfWeek = 3;
if (dayOfWeek >= 1 && dayOfWeek <= 5) Console.WriteLine("평일!");
else if (dayOfWeek == 6 || dayOfWeek == 7) Console.WriteLine("주말!");
else Console.WriteLine("잘못된 요일");
```
```csharp
// [과거 방식 (그룹핑)]
switch (dayOfWeek)
{
    case 1: case 2: case 3: case 4: case 5:
        Console.WriteLine("평일!"); break;
    case 6: case 7:
        Console.WriteLine("주말!"); break;
    default:
        Console.WriteLine("잘못된 요일"); break;
}

// [모던 C# 방식 (패턴 매칭)]
switch (dayOfWeek)
{
    case >= 1 and <= 5:   // switch 안에서 논리 연산이 가능!
        Console.WriteLine("평일!");
        break;
    case 6 or 7:
        Console.WriteLine("주말!");
        break;
    default:
        Console.WriteLine("잘못된 요일");
        break;
}
```

## 7. 실무 주의사항 및 안전 습관

* **항상 중괄호 `{ }`를 쳐라!** : 한 줄짜리 `if`문이라도 꼭 중괄호로 감싸세요. 나중에 코드를 추가하다가 괄호가 없어 엉뚱한 로직이 타는 버그는 찾기도 힘듭니다. (미래의 나를 위한 가장 싼 보험)
* **좁은 조건부터 검사하라** : `if-else if` 체인은 반드시 좁은 범위 ➔ 넓은 범위 순서로 작성해야 논리적 오류가 없습니다.
* **`switch`엔 항상 `default`를 넣어라** : "이외의 값은 안 들어오겠지?"라고 안일하게 생각하면 꼭 프로그램이 터집니다. 예상치 못한 예외 처리를 위해 `default`는 선택이 아닌 필수라 생각하세요.
* **조건식 안에서 할당(`=`) 금지** : `if (age = 20)`은 최악의 오타입니다. 비교는 항상 `==` 입니다.
