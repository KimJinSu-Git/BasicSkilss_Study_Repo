# [C# 기초] 3. 연산자 (Operators)

## 1. 연산자란?
연산자(Operator)는 프로그램 내에서 덧셈, 비교, 할당 등 특정 연산을 수행하도록 지시하는 특별한 기호입니다. 변수나 값(피연산자, Operand)과 함께 사용되어 새로운 값을 만들거나, 조건을 확인하거나, 코드의 흐름을 결정합니다.

> ** 직관적인 비유 : 연산자는 요리 도구와 같습니다.**
> * **재료 (피연산자)** : `10`, `score`, `playerName` 같은 변수나 값
> * **요리 도구 (연산자)** : `+` (칼), `==` (저울), `=` (그릇에 담기)
> * **완성된 음식 (결과)** : 연산을 통해 만들어진 새로운 값

**왜 필요한가?**
연산자가 없다면 가장 기본적인 덧셈조차 `Add(10, 5)` 같은 함수로 길게 풀어써야 합니다. 연산자는 기본 계산, 비교, 할당을 직관적인 기호로 표현하게 해주어 코드의 가독성을 극대화합니다.

## 2. 핵심 요약

| 종류 | 한 줄 설명 | 기호 예시 |
| :--- | :--- | :--- |
| **산술 연산자** | 사칙연산과 나머지 계산 | `+`, `-`, `*`, `/`, `%` |
| **비교 연산자** | 두 값을 비교하여 `bool` 반환 | `==`, `!=`, `<`, `>`, `<=`, `>=` |
| **논리 연산자** | `bool` 값의 조합 및 반전 | `&&`(AND), `\|\|`(OR), `!`(NOT) |
| **할당 연산자** | 변수에 값을 대입 및 누적 연산 | `=`, `+=`, `-=`, `*=`, `/=` |
| **증감 연산자** | 값을 1씩 증가 또는 감소 | `++`, `--` |
| **삼항 연산자** | 한 줄로 끝내는 간단한 조건 분기 | `조건 ? 참값 : 거짓값` |

## 3. 세부 개념 및 실무 팁

### 3.1 산술 연산자와 문자열 결합
* 기본 수학 계산: `+`, `-`, `*`, `/`(나누기), `%`(나머지)
* **정수 나눗셈 함정**: `int result = 10 / 3;` → 결과는 3 (소수점 버림). 정확한 실수가 필요하면 `10.0 / 3.0`처럼 피연산자 중 하나를 실수로 만들어야 합니다.
* **문자열 결합**: `+` 기호 양옆 중 하나라도 문자열(`string`)이 있으면, 수학 덧셈이 아니라 **글자를 이어 붙이는 역할**을 합니다. (예: `"Level " + 5` ➔ `"Level 5"`)

### 3.2 비교 연산자
두 값을 비교해 `true` 또는 `false` 결과를 냅니다. 조건문/반복문의 뼈대입니다.

### 3.3 논리 연산자와 단축 평가 (Short-Circuit)
| 연산자 | 의미 | 결과가 true인 경우 |
| :--- | :--- | :--- |
| `&&` | AND (그리고) | **양쪽 모두** true일 때만 |
| `\|\|` | OR (또는) | **어느 한쪽이라도** true면 |
| `!` | NOT (부정) | true ↔ false 반전 |

> **단축 평가 (Short-Circuit Evaluation)**
> C#은 아주 영리하고 게으릅니다. `A && B`를 검사할 때, **A가 false면 B는 아예 쳐다보지도 않고 false로 끝내버립니다.**\
> 이를 활용해 `if (player != null && player.hp > 0)` 라고 쓰면, `player`가 없을 때(null) 뒤의 `hp`를 확인하다가 발생하는 치명적인 에러를 막을 수 있습니다.

### 3.4 증감 연산자 (전위 vs 후위)
* `++count;` **(전위)** : 값을 **먼저** 1 증가시킨 뒤, 그 줄의 코드를 실행합니다.
* `count++;` **(후위)** : 그 줄의 코드를 **현재 값으로 먼저 실행**한 뒤, 맨 마지막에 값을 1 증가시킵니다.

## 4. 코드로 보는 연산자

### 4.1 기본 예시
```csharp
// 후위 증감 vs 전위 증감
int a = 5;
int b = a++; // b에 현재값(5)을 먼저 할당하고, 그 다음 a를 6으로 증가시킴
Console.WriteLine($"a: {a}, b: {b}"); // 결과 - a: 6, b: 5

int c = 5;
int d = ++c; // c를 먼저 6으로 증가시키고, 그 결과를 d에 할당함
Console.WriteLine($"c: {c}, d: {d}"); // 결과 - c: 6, d: 6

// 삼항 연산자 (조건 ? 참 : 거짓)
int score = 85;
string grade = score >= 90 ? "A" : "B";
Console.WriteLine($"등급: {grade}"); // 결과 - 등급: B
```

### 4.2 잘못된 코드와 올바른 사용법
```csharp
// ❌ 잘못된 코드 
int a = 5 / 2;             // a == 2 (2.5를 기대했다면 실패)
if (userAge = 20) { }      // CS0029 에러! =는 할당입니다.
string g = score > 90 ? "A" : score > 80 ? "B" : "C"; // 심각한 중첩 삼항 가독성

// ⭕ 올바른 코드
double a = 5.0 / 2.0;      // 2.5 (실수 나눗셈)
if (userAge == 20) { }     // 비교는 == 사용! (C#은 조건문에 bool 타입만 깐깐하게 허용합니다)

// 3가지 이상 분기는 삼항보다 if-else가 압도적으로 좋습니다.
string g;
if (score > 90) g = "A";
else if (score > 80) g = "B";
else g = "C";
```

## 5. 활용 예시 (게임 도메인)

플레이어가 특정 스킬을 사용할 수 있는지 여러 조건을 조합해 검사합니다.

```csharp
int playerLevel = 25;
int mana = 80;
bool hasCooltime = false;

// 스킬 사용 조건: 레벨 20 이상이면서 (마나 100 이상이거나 쿨타임이 없어야 함)
// 우선순위가 헷갈리면 무조건 괄호()를 써라! 미래의 자신을 위한 배려입니다.
bool canUseSkill = playerLevel >= 20 && (mana >= 100 || !hasCooltime);

if (canUseSkill)
{
    Console.WriteLine("스킬 사용 가능!");
}
else
{
    Console.WriteLine("조건 불충족");
}
```

## 6. Unity에서의 연산자 활용

Unity에서는 `Vector2`, `Vector3` 같은 수학 구조체에 연산자 오버로딩(Overloading)이 되어 있어서, 복잡한 3D 수학을 사칙연산 기호 하나로 편하게 쓸 수 있습니다.

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    public int hp = 100;
    public Vector3 velocity = new Vector3(1, 0, 0); // 우측으로 향하는 방향 벡터

    void Update()
    {
        // Vector3 사칙연산 (+, *)
        // 원래는 좌표 x, y, z를 각각 더해야 하지만, + 기호 하나로 물리 공식 쓰듯 자연스럽게 표현!
        transform.position += velocity * Time.deltaTime;

        // Mathf 산술 도우미
        hp = Mathf.Clamp(hp, 0, 100); // 체력을 0~100 사이로 강제 고정

        // 논리 연산자
        if (hp <= 0 && !isInvincible)
        {
            Debug.Log("Game Over");
        }
    }
}
```

## 7. 실습 문제 및 복습

**Q1. 10,000원을 내고 3,500원짜리 물건을 샀을 때, 거스름돈을 계산하고 500원 동전이 최대 몇 개 나오는지 계산하세요.**
```csharp
int paid = 10000;
int price = 3500;
int change = paid - price;              // 거스름돈: 6500
int coin500Count = change / 500;        // 동전 개수: 13 (몫만 반환됨)
Console.WriteLine($"거스름돈: {change}원, 500원 동전 {coin500Count}개");
```

**Q2. 아래 코드의 `canAttack`이 `true`일지 `false`일지 논리 연산자 우선순위에 근거해 설명하세요.**
```csharp
int playerLevel = 50;
float distanceToBoss = 12.5f;
bool hasRequiredItem = true;

bool canAttack = playerLevel >= 60 && distanceToBoss < 10.0f || hasRequiredItem;
```
> **정답: `true`**\
> `&&`(AND)가 `||`(OR)보다 우선순위가 높습니다. 따라서 식은 `(A && B) || C`로 해석됩니다.\
> `(50 >= 60) && (12.5 < 10.0)` = `false && false` = `false`\
> 최종적으로 `false || true`가 되어 결과는 `true`가 됩니다. (만약 의도가 달랐다면 반드시 괄호를 쳐야 합니다)

**Q3. 삼항 연산자를 중첩 사용하면 안 되는 이유를 설명하세요.**
> 중첩된 삼항 연산자는 코드를 읽는 사람이 어디서 조건이 분기되는지 시각적으로 추적하기 매우 어렵습니다.\
> 조건이 늘어날수록 디버깅과 수정이 까다로워지므로, 2단계를 넘어가는 분기는 `if-else`나 `switch`문을 사용하는 것이 훨씬 안전하고 가독성이 좋습니다.

## 8. 주의사항 및 실무 안전 습관

* **괄호를 적극적으로 사용하라!** : 연산자 우선순위표를 외우려 하지 말고, 내가 먼저 계산하고 싶은 묶음에 괄호 `()`를 치세요.
* **`=` (할당)과 `==` (비교) 절대 혼동 금지** : 가장 흔하고 잡기 힘든 논리 버그의 주범입니다.
* **삼항 연산자는 딱 1단계까지만** : "참석? O : X" 처럼 단순한 할당 분기에만 사용하세요.
* **bool 변수 네이밍** : `isAlive`, `hasItem`, `canJump` 처럼 `is~`, `has~`, `can~` 접두어를 붙이면 코드가 영어 문장처럼 읽혀 가독성이 상승합니다.
