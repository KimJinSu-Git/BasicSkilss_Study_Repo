# [C# 기초] 2. 자료형 (Data Type)

## 1. 자료형이란?
자료형(Data Type)은 변수가 어떤 종류의 데이터를 저장할 수 있는지, 그리고 그 데이터를 위해 메모리를 얼마나 사용해야 하는지를 정의하는 '설명서' 또는 '규칙'입니다.

> **💡 직관적인 비유 : 내용물별로 모양이 다른 보관 용기**
> - `int` : 작은 숫자(정수)를 담는 네모난 상자
> - `long` : 아주 큰 숫자를 담는 거대한 상자
> - `float` / `double` : 소수점이 있는 숫자를 정밀하게 담는 눈금 비커
> - `bool` : '예/아니오' 스위치가 달린 작은 컨트롤 박스
> - `string` : 여러 글자를 실로 꿰어놓은 문자열 목걸이

C#은 **정적 형식(Statically-Typed) 언어**입니다.\
따라서 변수를 만들기 전에 "이 상자에는 정수만 담을 겁니다!"라고 반드시 명시해야 합니다. 데이터에 딱 맞는 보관함을 지정하면 메모리를 낭비 없이 쓸 수 있고, 타입이 다른 값을 잘못 넣는 실수(예: 숫자 상자에 글자를 넣는 행위)를 컴파일 단계에서 100% 차단해 줍니다.

## 3. 세부 개념: 값 형식 vs 참조 형식 (중요 ⭐)

C#의 모든 데이터 타입은 크게 **값 형식**과 **참조 형식**으로 나뉩니다. 메모리 관리의 첫걸음입니다.

### 3.1 값 형식 (Value Type)
변수 자체가 데이터의 실제 값을 들고 있습니다. (주로 스택(Stack) 메모리 사용)
* **특징:** 다른 변수에 대입하면 값이 **통째로 복사(Copy)** 됩니다. 복사본을 지지고 볶아도 원본에는 전혀 영향이 없습니다.

### 3.2 참조 형식 (Reference Type)
데이터의 실제 값은 힙(Heap) 메모리에 두고, 변수는 그 데이터가 있는 '주소(위치)'만 들고 있습니다.
* **특징:** 다른 변수에 대입하면 **주소만 복사**됩니다. 즉, 두 변수가 하나의 본체를 같이 가리키게 되어, 한쪽을 변경하면 다른 쪽도 같이 변경되는 효과가 나타납니다.

> **`string`의 특이한 성질 (불변성)**\
> `string`은 참조 형식입니다. 하지만 대입하고 값을 변경해도 원본이 바뀌지 않는데, 이는 `string`이 불변(Immutable)이기 때문입니다.\
> 글자를 수정하는 순간 기존 본체를 바꾸는 게 아니라, 완전히 **새로운 문자열을 메모리에 만들고** 그 새 주소를 가리키게 됩니다.


### 3.3 기본 자료형 한 눈에 보기

| 자료형         | .NET 형식        | 크기      | 대표 용도                   |
|:------------|:---------------|:--------|:------------------------|
| **bool**    | System.Boolean | 1 byte  | 로그인 상태, 활성화 여부          |
| **char**    | System.Char    | 2 byte  | 단일 문자('A', '가')         |
| **int**     | System.Int32   | 4 byte  | 나이, 레벨, 점수 (가장 흔한 정수)   |
| **long**    | System.Int64   | 8 byte  | 매우 큰 정수 (DB ID, 인구)     |
| **float**   | System.Single  | 4 byte  | 게임 좌표, 이동 속도 (f 접미사 필수) |
| **double**  | System.Double  | 8 byte  | 과학 계산, 높은 정밀도 실수        |
| **decimal** | System.Decimal | 16 byte | 금융 계산 (오차 절대 금물, m 접미사) |
| **string**  | System.String  | 가변      | 모든 종류의 문자열              |

## 4. 코드로 보는 자료형

### 4.1 기본 문법과 접미사(Suffix)
```csharp
// 정수형
int level = 1;
long population = 5000000000L; // L 접미사 (long임을 명시)

// 실수형 (소수점)
float moveSpeed = 1.5f;        // f 접미사 필수! (안 쓰면 double로 인식)
double pi = 3.1415926535;      // 접미사 없음 (기본 실수형)
decimal price = 19900m;        // m 접미사 (오차가 없어야 하는 금융 계산용)

// 문자/문자열
char grade = 'A';              // 작은따옴표 (단일 문자 1개)
string playerName = "홍길동";    // 큰따옴표 (문자열)

// 논리형
bool isAlive = true;           // true 또는 false
```

### 4.2 값 형식 vs 참조 형식 복사 테스트
```csharp
using System;

public class MemoryExample
{
    public static void Main()
    {
        // [값 형식] — 값이 통째로 복사됨
        int a = 10;
        int b = a;     // a의 값 '10'이 b에 복사됨
        b = 20;        // b만 변경
        Console.WriteLine($"a: {a}, b: {b}");  // 결과: a: 10, b: 20 (서로 독립적)

        // [참조 형식] — 주소만 복사됨
        int[] arrA = { 1, 2, 3 };
        int[] arrB = arrA;   // arrA가 가리키는 '주소'가 arrB에 복사됨
        arrB[0] = 99;        // arrB의 0번째 값을 바꿨지만
        Console.WriteLine($"arrA[0]: {arrA[0]}, arrB[0]: {arrB[0]}"); // 결과: 둘 다 99!
    }
}
```

### 4.3 형변환 (Type Casting)
```csharp
// 암묵적 형변환 (작은 상자 -> 큰 상자: 안전함)
int level = 10;
double doubleLevel = level; // 아무 문제 없이 들어감

// 명시적 형변환 (큰 상자 -> 작은 상자: 데이터 손실 위험)
double pi = 3.14;
// int piInt = pi;  <- 에러 발생 (0.14가 날아갈 수 있습니다)
int piInt = (int)pi; // "손실 감수할 테니 그냥 int로 바꿔주세요" (명시적 캐스팅)
```

## 5. 게임 도메인 활용 예시

온라인 상점의 상품 정보를 데이터 성격에 맞는 자료형으로 설계해 봅시다.

```csharp
long productCode = 123456789012L; // 일반 int 범위를 넘어서는 큰 숫자
string productName = "고성능 기계식 키보드";
int price = 159000;               // 소수점이 필요 없는 돈/재화
decimal discountRate = 0.15m;     // 정확한 계산이 필요한 비율 (오차 방지)
float starRating = 4.8f;          // 적당한 정밀도만 필요한 게임 내 수치
bool onSale = true;               // 상태(참/거짓)

Console.WriteLine($"상품 코드: {productCode}");
Console.WriteLine($"할인율: {discountRate * 100}%");
```
> **데이터의 성격에 맞는 자료형 선택은 메모리 효율과 프로그램 정확성의 출발점입니다.**

## 6. Unity에서의 자료형

Unity에서는 우리가 선언한 자료형에 따라 인스펙터(Inspector) 창의 UI 위젯이 자동으로 변합니다.

```csharp
using UnityEngine;

public class PlayerSettings : MonoBehaviour
{
    // SerializeField를 붙이면 자료형에 맞춰 Unity 인스펙터에 자동 세팅됩니다.
    [SerializeField] private int _maxHealth = 100;           // 정수 입력 칸
    [SerializeField] private float _moveSpeed = 5.5f;        // 실수 입력 칸
    [SerializeField] private string _playerName = "전사";      // 텍스트 박스
    [SerializeField] private bool _isInvincible = false;     // 체크박스 (토글)
    
    // Unity가 제공하는 자체 구조체(Struct, 값 형식)
    [SerializeField] private Vector3 _startPosition;         // X, Y, Z 3개의 입력 칸
}
```

**Q4. 캐릭터의 '초당 공격 횟수(예: 1.5)'를 저장할 때 `float`와 `double` 중 어떤 것이 적합한가요?**

> 3. **호환성:** Unity를 포함한 대부분의 게임 엔진은 3D 연산 시 성능을 위해 `float`을 기본 표준으로 사용합니다.

## 8. 주의사항 및 실무 안전 습관

* **정수 나눗셈의 함정 (매우 중요)**: `5 / 2`의 결과는 `2.5`가 아니라 `2`입니다. 정수끼리 나누면 소수점은 버려집니다. 제대로 된 결과를 얻으려면 `5.0f / 2`처럼 하나라도 실수형으로 만들어야 합니다.
* **접미사 누락 주의**: `float x = 1.5;` (X) -> `float x = 1.5f;` (O)
* **`var` 키워드 오해 금지**: `var age = 20;`을 쓰면 알아서 `int`로 선언됩니다. 코드가 간결해지지만, 한 번 `int`로 정해지면 중간에 문자열을 넣을 수 없는 **강력한 정적 타입**이라는 것을 명심하세요.
