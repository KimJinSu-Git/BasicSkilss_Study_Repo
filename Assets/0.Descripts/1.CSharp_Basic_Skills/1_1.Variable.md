# [C# 기초] 1. 변수 (Variable)

## 1. 변수란?
변수(Variable)는 **데이터를 저장하기 위해 이름을 붙인 메모리 공간**입니다.\
프로그램이 실행되는 동안 필요한 값을 임시로 보관하는 장소이며, 학창 시절의 **사물함**이라고 생각하면 이해하기 쉽습니다.

* **사물함 크기 (자료형)** : 어떤 물건(데이터)을 넣을지 결정하는 사물함의 규격
* **이름표 (변수 이름)** : 복잡한 메모리 주소(예: `0X1A2B`) 대신, 우리가 찾아가기 쉽게 붙여둔 이름표
* **보관함 속 물건 (값)**: 변수에 실제로 저장된 데이터

> **💡 변수가 왜 필요할까요?**
> 변수가 없다면 우리는 데이터가 저장된 복잡한 메모리 주소를 전부 외워야 합니다.\
> 변수는 그 복잡한 주소 대신 `playerName`, `score`처럼 의미 있는 이름을 부여해서 코드를 읽기 쉽고 관리하기 편하게 만들어 줍니다.

## 2. 변수의 생명주기 (선언, 할당, 초기화)

변수를 사용하려면 3가지 단계를 거칩니다. 실무에서는 '선언과 동시에 초기화'하는 것을 가장 권장합니다.

| 개념 | 설명 | 문법 예시 | 사물함 비유 |
| :--- | :--- | :--- | :--- |
| **선언 (Declaration)** | 메모리에 데이터 공간을 확보 | `int level;` | "숫자용 사물함을 만들고 이름은 level로 해줘" |
| **할당 (Assignment)** | 선언된 공간에 실제 값을 넣음 | `level = 1;` | "level 사물함에 1을 넣어줘" |
| **초기화 (Initialization)**| 선언과 할당을 **한 줄로** 처리 | `int level = 1;` | 사물함을 만들자마자 바로 1을 넣음 |

### 🚨 C#의 안전장치
C#은 초기화되지 않은 변수를 사용하려고 하면 컴파일 오류(`CS0165`)를 냅니다.
* **이유:** 메모리 공간에 예전에 쓰다 남은 알 수 없는 값(쓰레기 값)이 들어있을 수 있는데, 이를 잘못 읽어서 치명적인 버그가 발생하는 것을 원천 차단하기 위함입니다.

## 3. 명명 규칙 (Naming Conventions)

C#에서 변수 이름을 지을 때는 약속된 규칙이 있습니다. 혼자 개발할 때도 이 규칙을 지켜야 나중에 협업하기 좋습니다.

| 규칙 | 사용처 | 예시 |
| :--- | :--- | :--- |
| **camelCase** | 지역 변수, 매개 변수 (첫 단어 소문자, 이후 대문자) | `int itemCount;` |
| **_camelCase** | 클래스의 멤버 변수(필드) (언더바로 시작) | `int _playerHealth;` |
| **PascalCase** | 클래스, 메서드, 프로퍼티 (모든 단어 첫 글자 대문자)| `class PlayerController` |
| **금지 사항** | 숫자 시작, 예약어(`string`, `int` 등), 특수문자 | `1stPlayer`, `int`, `@name` (X) |

## 4. 코드로 보는 변수 사용법

```csharp
using System;

public class VariableExample
{
    public static void Main()
    {
        // 선언 및 초기화 (가장 권장되는 방식)
        int level = 1;
        Console.WriteLine($"현재 레벨: {level}"); // 출력: 1

        // 값의 변경 (재할당)
        // 변수는 '변할 수 있는 수'입니다. 새로운 값을 넣으면 이전 값은 덮어씌워져 사라집니다.
        level = 5; 
        Console.WriteLine($"레벨 업! 현재 레벨: {level}"); // 출력: 5
        
        // 잘못된 예 (컴파일 오류 발생)
        // int experience;
        // Console.WriteLine(experience); -> CS0165 에러! (초기화되지 않은 변수 사용)
    }
}
```

## 5. 게임 도메인 활용 예시

RPG 게임에서 캐릭터가 몬스터에게 공격받아 체력이 깎이는 상황을 변수로 표현해 봅시다.\
게임의 상태는 결국 **변수들의 모음**이고, 변수의 변화를 추적하는 것이 게임 로직의 본질입니다.

```csharp
using System;

public class GameLogic
{
    public static void Main()
    {
        // 캐릭터 초기 스탯 설정 (다양한 자료형 사용)
        string characterName = "광전사";  // 문자열
        int health = 100;                 // 정수
        float attackPower = 15.5f;        // 실수
        bool isAlive = true;              // 참/거짓

        Console.WriteLine($"이름: {characterName}, 체력: {health}");

        // 몬스터의 공격! (30 데미지)
        health = health - 30;             // 기존 체력에서 30을 빼서 다시 health에 할당
        isAlive = (health > 0);           // 체력이 0보다 크면 true, 아니면 false

        Console.WriteLine($"공격받음! 남은 체력: {health}, 생존 여부: {isAlive}");
    }
}
```

## 6. Unity에서의 변수 활용

Unity에서 변수는 스크립트(코드)와 유니티 에디터(인스펙터)를 연결해주는 아주 중요한 역할을 합니다.

```csharp
using UnityEngine;

public class Player : MonoBehaviour
{
    // [SerializeField]: 접근 제어자는 private으로 보호하면서, 
    // Unity 에디터(인스펙터 창)에서는 이 변수를 직접 보고 수정할 수 있게 해줍니다
    [SerializeField] private int _health = 100;
    [SerializeField] private float _moveSpeed = 5.5f;

    void Start()
    {
        // Unity에서는 Console.WriteLine 대신 Debug.Log를 사용합니다.
        Debug.Log($"플레이어의 시작 체력은 {_health} 입니다.");
    }
}
```
> **핵심 포인트:** 이렇게 작성하면 코드를 다시 빌드하지 않고도 유니티 에디터 창에서 기획자가 직접 체력과 이동 속도 밸런스를 조절할 수 있습니다!

## 7. 스코프 (Scope) : 변수의 수명

변수는 아무 곳에서나 사용할 수 없습니다. 자기가 선언된 **중괄호 `{ }` (블록)** 안에서만 살아있고, 밖으로 나가면 메모리에서 사라집니다.

```csharp
void Attack()
{
    int damage = 50; // damage 변수 탄생
    Console.WriteLine(damage);
} // <- damage 변수 사망 (메모리 해제)

void Defend()
{
    // Console.WriteLine(damage); <- 에러! damage라는 변수를 찾을 수 없음
}
```

## 8. 실습 문제 및 복습

**Q1. 변수란 무엇인지 '메모리'와 '이름' 키워드로 한 문장으로 설명하세요.**
> 변수는 데이터(값)를 임시로 보관하기 위해 **메모리** 공간에 **이름**을 붙인 것입니다.

**Q2. C#이 초기화되지 않은 변수를 막는 이유를 설명해보세요.**
> 쓰레기 값을 읽어 발생하는 미정의 동작(치명적인 버그)을 컴파일 단계에서 미리 차단하기 위한 C#의 안전장치입니다.

**Q3. 이름, 나이, C# 학습 여부를 변수로 선언/초기화하고 출력하는 코드를 작성하세요.**
```csharp
string name = "홍길동";
int age = 25;
bool isLearningCSharp = true;

// $ 기호를 문자열 앞에 붙이면(문자열 보간), 문자열 안에 중괄호 {}를 사용해 변수를 바로 넣을 수 있습니다.
Console.WriteLine($"제 이름은 {name}이고 나이는 {age}살입니다. C# 학습: {isLearningCSharp}");
```

**Q4. 다음 코드의 잘못된 부분을 모두 찾고 이유를 설명하세요.**
```csharp
// 1. string string = "Hello";
// 2. int user Age = 30;
// 3. float 3.14f = pi;
```
> 1. `string`은 C#의 예약어이므로 변수명으로 사용할 수 없습니다. (예: `string myString = "Hello";` 로 수정)
> 2. 변수명(`user Age`)에는 공백이 들어갈 수 없습니다. (예: `int userAge` 로 수정)
> 3. 할당 연산자(`=`)는 오른쪽의 값을 왼쪽 변수에 넣습니다. 좌우가 바뀌었고, 변수명은 숫자로 시작할 수 없습니다. (예: `float pi = 3.14f;` 로 수정)

**Q5. 게임 캐릭터의 '공격 속도'를 `float attackSpeed = 1.2f;`와 `int attackSpeed = 1;` 중 어떤 것으로 선언할지 이유와 함께 설명하세요.**
> `float`가 적절합니다. 공격 속도는 0.8, 1.2, 1.75 같은 소수점(연속적인 값)을 가져야 디테일한 밸런스 조절이 가능한데, 정수형(`int`)은 이를 표현할 수 없습니다.
