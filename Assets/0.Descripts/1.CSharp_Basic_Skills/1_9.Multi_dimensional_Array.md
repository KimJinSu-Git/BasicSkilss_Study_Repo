# [C# 기초] 9. 다차원 배열 (Multi-dimensional Array)

## 1. 다차원 배열이란?
1차원 배열이 한 줄로 길게 이어진 기차라면, 다차원 배열(Multi-dimensional Array)은 여러 기차를 나란히 세워둔 기차역이나 층과 호수가 있는 아파트와 같습니다.\
데이터를 행(Row)과 열(Column)이 있는 표(Table)나 입체적인 공간 형태로 저장하는 자료구조입니다.

> **비유 : 엑셀 시트와 바둑판**
> * **행 (Row)** : 가로줄 (1행, 2행, 3행...) ➔ **Y축** 역할
> * **열 (Column)** : 세로줄 (A열, B열, C열...) ➔ **X축** 역할
> * **셀 (Cell)** : 행과 열이 만나는 한 칸 (`[1, A]`, `[2, B]`)

**왜 필요한가?**\
게임 맵의 (x, y) 좌표, 체스판, 인벤토리 슬롯 같은 격자(Grid) 형태의 데이터는 1차원 배열만으로는 직관적으로 표현하기 어렵습니다. 다차원 배열은 이런 2D/3D 공간 데이터를 시각적인 형태 그대로 코드에 옮길 수 있게 해줍니다.

## 2. 핵심 요약

| 종류 | 한 줄 설명 | 문법 예시 |
| :--- | :--- | :--- |
| **2차원 배열 `[,]`** | 모든 행의 길이가 같은 직사각형 격자 (가장 많이 씀) | `int[,] grid = new int[3, 4];` |
| **가변 배열 `[][]`** | 행마다 길이가 다를 수 있는 '배열의 배열' (톱니바퀴형)| `int[][] jagged = new int[3][];` |
| **접근 방식** | 2차원 배열은 쉼표(`,`), 가변 배열은 대괄호(`[][]`) 사용 | `grid[row, col]`, `jagged[row][col]` |
| **길이 조회** | `GetLength(0)`은 행의 개수, `GetLength(1)`은 열의 개수 | `grid.GetLength(0)` |

## 3. 세부 개념 및 구조 비교

### 3.1 2차원 배열 (Rectangular Array) - `[,]`
모든 행이 동일한 개수의 열을 가지는 완벽한 직사각형 구조입니다.
* 모든 요소가 하나의 연속된 메모리 블록에 저장되어 **가비지 컬렉터(GC) 부담이 적습니다.**
* 용도: 타일 맵, 틱택토, 좌석 배치 등 꽉 찬 격자 데이터

### 3.2 가변 배열 (Jagged Array) - `[][]`
1차원 배열들을 요소로 가지는 '배열의 배열'입니다. 각 행마다 길이가 들쭉날쭉할 수 있습니다.
* 바깥쪽 배열을 먼저 만들고, 각 행마다 `new`를 따로 호출해 안쪽 배열을 만들어야 합니다.
* 용도: 스킬 트리, 퀘스트 분기점, 학생별 수강 과목 등 비정형 데이터

### 3.3 2차원 배열 vs 가변 배열 한눈에 보기
| 항목 | 2차원 배열 (`[,]`) | 가변 배열 (`[][]`) |
| :--- | :--- | :--- |
| **모양** | 완벽한 직사각형 | 들쭉날쭉함 (톱니바퀴형) |
| **메모리 구조**| 한 덩어리 (연속 할당) | 여러 덩어리 (분산 할당) |
| **초기화 방식**| 단일 `new` (`new int[3,3]`) | 바깥쪽 `new` 후 행마다 `new` 호출 |
| **접근 속도** | (C# 기준) 수학적 계산 필요로 약간 느림 | (C# 기준) 포인터 직접 접근으로 매우 빠름 |

## 4. 코드로 보는 다차원 배열

### 4.1 선언과 할당, 초기화
```csharp
// 1. 2차원 배열 (3행 4열)
int[,] arr2D = new int[3, 4];
arr2D[0, 1] = 10;
int rows = arr2D.GetLength(0); // 3 (행)
int cols = arr2D.GetLength(1); // 4 (열)

// 값과 함께 바로 초기화
int[,] bingo = {
    { 1, 2, 3 },
    { 4, 5, 6 },
    { 7, 8, 9 }
};

// 2. 가변 배열 (3개의 행)
int[][] jagged = new int[3][]; 
jagged[0] = new int[5]; // 0행은 길이 5
jagged[1] = new int[2]; // 1행은 길이 2
jagged[2] = new int[4]; // 2행은 길이 4

jagged[0][0] = 100;
```

### 4.2 흔한 실수와 방어 코드
```csharp
// 실수 1: 가변 배열의 안쪽 미생성
int[][] myJagged = new int[3][];
myJagged[0][0] = 100; // NullReferenceException 발생! 안쪽 배열을 new 하지 않음.

// 실수 2: 행과 열의 헷갈림
int[,] grid = new int[10, 5]; // 10행 5열
grid[3, 7] = 1; // IndexOutOfRangeException! 열(Column)은 최대 4까지만 가능함.

// 올바른 접근 (변수명 명확화)
int row = 3, col = 4;
if (row < grid.GetLength(0) && col < grid.GetLength(1))
{
    grid[row, col] = 1; // 안전한 접근
}
```

## 5. 실전 활용 예시 (영화관 예매 시스템)

문자(`'A'`)를 수학적으로 계산해 인덱스(`0`)로 변환하는 예제입니다.

```csharp
public class MovieTheater
{
    private int[,] _seats;

    public MovieTheater(int rows, int cols)
    {
        _seats = new int[rows, cols]; // 0: 빈자리, 1: 예매됨
    }

    public void PrintSeatMap()
    {
        Console.WriteLine("=== 좌석 배치도 ===");
        for (int i = 0; i < _seats.GetLength(0); i++)
        {
            Console.Write($"{(char)('A' + i)}열 "); // A, B, C... 
            
            for (int j = 0; j < _seats.GetLength(1); j++)
            {
                Console.Write(_seats[i, j] == 0 ? "□ " : "■ ");
            }
            Console.WriteLine(); // 줄바꿈
        }
    }

    public bool ReserveSeat(char rowChar, int colNum)
    {
        // 실무 팁: 아스키코드 연산을 통해 문자를 0부터 시작하는 인덱스로 변환!
        int row = rowChar - 'A'; 
        int col = colNum - 1;

        // 가드 절: 범위를 벗어난 예매 차단
        if (row < 0 || row >= _seats.GetLength(0) || col < 0 || col >= _seats.GetLength(1))
        {
            Console.WriteLine("잘못된 좌석 번호입니다.");
            return false;
        }

        if (_seats[row, col] == 1)
        {
            Console.WriteLine("이미 예매된 좌석입니다.");
            return false;
        }

        _seats[row, col] = 1; // 예매 완료
        return true;
    }
}
```

## 6. Unity에서의 배열 활용 (좌표계 주의!)

Unity에서 타일 맵을 다룰 때 2차원 배열을 주로 사용합니다. 여기서 가장 중요한 것은 **`(X, Y)` 좌표와 `[Row, Col]`의 매칭**입니다.

```csharp
using UnityEngine;

public class MapGenerator : MonoBehaviour
{
    public int width = 20;  // X축
    public int height = 15; // Y축
    public GameObject tilePrefab;

    private GameObject[,] _tiles;

    void Start()
    {
        _tiles = new GameObject[height, width]; // [행(Y), 열(X)] 순서로 배열 생성

        // 캐시 효율을 위해 바깥 루프를 행(Y축), 안쪽 루프를 열(X축)로 돕니다.
        for (int y = 0; y < height; y++)
        {
            for (int x = 0; x < width; x++)
            {
                Vector3 pos = new Vector3(x, y, 0); // Unity 물리 좌표
                
                // 주의: 배열 접근은 항상 [행(Y), 열(X)] 순서입니다! 
                _tiles[y, x] = Instantiate(tilePrefab, pos, Quaternion.identity);
            }
        }
    }
}
```
> **핵심 원칙**: 2D 게임의 화면은 가로가 X, 세로가 Y입니다. 하지만 배열에서 세로를 나타내는 행(Row)은 첫 번째 인자이므로, **Unity에서는 항상 `배열[y, x]` 형태로 접근해야 시각적 맵과 논리적 배열이 정확히 일치합니다.**

### 최적화 꿀팁: 1차원 배열로 2D 흉내내기 (Flattening)
모바일 게임 등 최적화가 극한으로 필요할 때는, `[,]`나 `[][]` 대신 그냥 1차원 배열을 씁니다!
```csharp
// 10x10 2차원 맵을 100칸짜리 1차원 배열 하나로 만듭니다.
int[] flatMap = new int[width * height]; 

// 특정 (x, y) 좌표에 접근하는 공식!
int index = y * width + x; 
flatMap[index] = 1; 
```
이러면 연속된 메모리(캐시 친화적), 단일 객체 할당(GC 최소화), 초고속 접근이라는 3마리 토끼를 다 잡을 수 있습니다.

## 7. 실습 문제 및 복습

**Q1. `int[,]`와 `int[][]`의 가장 큰 구조적 차이는?**
> * `int[,]`는 직사각형 모양으로 메모리가 한 덩어리(연속적)로 생성됩니다.
> * `int[][]`는 각 행마다 길이가 다른 배열을 가질 수 있으며, 여러 덩어리로 분산되어 생성됩니다. 따라서 각 행을 따로 `new` 해주어야 사용할 수 있습니다.

**Q2. 9x9 구구단 표를 2차원 배열로 만들고 출력하세요.**
```csharp
int[,] gugudan = new int[9, 9];

for (int i = 0; i < 9; i++)
{
    for (int j = 0; j < 9; j++)
    {
        gugudan[i, j] = (i + 1) * (j + 1);
        Console.Write($"{gugudan[i, j],4}"); // 4칸씩 공간 확보하여 정렬 출력
    }
    Console.WriteLine();
}
```

**Q3. 2차원 배열 순회 시 `행 ➔ 열` 순서와 `열 ➔ 행` 순서 중 어느 쪽이 성능에 유리할까요?**
> **`행 ➔ 열` (Row-major) 순서가 압도적으로 유리합니다.**\
> C#의 2차원 배열은 메모리에 같은 행의 데이터가 나란히 붙어서 저장됩니다. 따라서 행을 먼저 잡고 열을 이동시키며 읽으면(`arr[0,0] ➔ arr[0,1] ➔ arr[0,2]`), CPU가 인접한 메모리를 캐시로 한꺼번에 가져와(Cache Hit) 처리 속도가 비약적으로 빨라집니다.

## 8. 주의사항 및 안전 습관

* **배열 크기 조회는 무조건 `GetLength()`** : 다차원 배열에서 `.Length`를 쓰면 3x4 배열의 경우 `12`라는 '전체 요소 수'를 뱉어버립니다. 행은 `GetLength(0)`, 열은 `GetLength(1)`을 쓰는 습관을 들이세요.
* **행(Row)과 열(Col)의 순서 혼동 금지** : 접근할 때 `[세로축(Y), 가로축(X)]` 임을 잊지 마세요.
* **변수명으로 방어하기** : 다차원 배열의 인덱스 변수로 `i`, `j`를 쓰면 헷갈리기 쉽습니다. 반드시 `row`, `col` 또는 `y`, `x`를 사용하여 직관성을 높이세요.
