# [Fundamentals] 12. Physics2D (물리 2D 질의와 설정)

## 1. Physics2D 란?
> **심판이자 경기장**
> * 앞선 챕터의 `Rigidbody2D`(몸무게)와 `Collider2D`(몸집)가 경기를 뛰는 '선수'라면, **`Physics2D`는 이 선수들이 뛰는 '경기장'이자 룰을 통제하는 '심판'** 입니다.
> * 중력을 지구처럼 할지 달처럼 할지, 어느 팀끼리 부딪히게 할지(레이어)를 심판이 전역으로 통제합니다.
> * 또한 심판에게 **"저쪽 벽 뒤에 누가 숨어있나요?"** 라고 물어보면(질의, Query), 심판이 빛의 속도로 훑어보고 정답을 알려줍니다.

**왜 필요한가?**\
충돌 콜백(`OnCollisionEnter`)은 "이미 부딪힌 다음"에야 불립니다. 하지만 게임을 만들다 보면 **부딪히기 전에 미리 알아야 할 일**이 산더미입니다.
1. "내 발밑 0.1m 아래에 바닥이 있는가?" (점프 가능 여부)
2. "내 앞 10m 시야 안에 적이 있는가?" (적 AI 인식)
3. "이 방향으로 대시(Dash)를 쓰면 벽에 안 박고 몇 m나 갈 수 있는가?"

이런 질문(질의)을 코드에서 내가 원할 때 능동적으로 묻고 답을 받아내는 기능이 바로 `Physics2D`의 핵심입니다.

## 3. 세부 개념 및 원리

### 3.1 질의(Query)의 두 갈래: Cast vs Overlap
이름이 열 개가 넘지만 규칙은 단순합니다. **모형(Ray, Circle, Box) × 방식(Cast, Overlap)** 의 조합입니다.

| 모형 | `Cast` (방향으로 쏜다)     | `Overlap` (제자리에 덮는다)          |
| :--- |:-----------------------|:--------------------------------|
| **Ray (선)** | `Physics2D.Raycast`    | `Physics2D.OverlapPoint` (점 하나) |
| **Circle (원)** | `Physics2D.CircleCast` | `Physics2D.OverlapCircle`       |
| **Box (상자)** | `Physics2D.BoxCast`    | `Physics2D.OverlapBox`          |

* **언제 뭘 쓰나요?**
    * 거리가 필요하다면 `Cast` ("내 앞 5m 공간이 비어있는가?")
    * 특정 구역에 무언가 존재하는지만 묻는다면 `Overlap` ("내 칼자루 반경 2m 안에 적이 있는가?")

### 3.2 `RaycastHit2D` : 광선에 맞은 놈의 신상정보
`Cast` 계열 함수를 쏘면 유니티는 `RaycastHit2D`라는 구조체를 던져줍니다. 이 안에는 엄청난 정보가 들어있습니다.

```csharp
// origin(시작점)에서 direction(방향)으로 distance(거리)만큼 쐈을 때 targetLayer(마스크)에 걸린 놈
RaycastHit2D hit = Physics2D.Raycast(origin, direction, distance, targetLayer);

// hit.collider가 null이 아니면 누군가 맞았다는 뜻
if (hit.collider != null)
{
    Collider2D other = hit.collider;      // 걸린 콜라이더 껍데기
    Vector2 point = hit.point;            // 광선이 정확히 맞은 '월드 좌표' (스파크 이펙트 터트릴 곳)
    Vector2 normal = hit.normal;          // 광선이 맞은 벽의 '수직 방향 벡터' (반사각 계산용)
    float dist = hit.distance;            // 내가 쏜 곳에서부터 맞은 곳까지의 실제 거리
}
```

### 3.3 [심화 팁] 빛의 반사각 구하기 (`Vector2.Reflect`)
벽에 광선을 쏴서 맞췄을 때, 당구공이나 빛(레이저)처럼 입사각=반사각으로 튕겨나가는 벡터를 구하는 함수입니다.

```csharp
// 1. 벽을 향해 레이저를 쏜다
RaycastHit2D hit = Physics2D.Raycast(firePoint, shootDirection, 100f, wallLayer);

if (hit.collider != null)
{
    // 2. 튕겨나갈 방향 = Vector2.Reflect(내가 쏜 방향, 벽이 쳐다보는 수직 방향)
    Vector2 reflectDir = Vector2.Reflect(shootDirection, hit.normal);
    
    // 3. 튕긴 곳(hit.point)에서 reflectDir 방향으로 다시 쏘면 반사 퍼즐 완성
}
```

## 4. 코드로 보는 실수

### 잘못된 판정 (마스크 미사용)
```csharp
// 의도: 내 앞에 적이 있는지 확인하고 싶다
// 실제: 자기 자신 몸뚱이나 허공의 투명한 이벤트 트리거에 걸려서 거리 0으로 실패함.
RaycastHit2D hit = Physics2D.Raycast(transform.position, transform.right, 5f);
```

### 완벽한 판정 (마스크 사용 + 기즈모 그리기)
```csharp
public class ObstacleProbe : MonoBehaviour
{
    [SerializeField] private float detectionDistance = 5f;
    [SerializeField] private LayerMask obstacleLayer; // 인스펙터에서 적/장애물 레이어만 체크

    private bool _isDetected;
    private float _lastHitDistance;

    private void Update()
    {
        // 내 몸통을 건너뛰고 정확히 원하는 레이어만 때린다
        RaycastHit2D hit = Physics2D.Raycast(transform.position, transform.right, detectionDistance, obstacleLayer);

        _isDetected = hit.collider != null;
        _lastHitDistance = _isDetected ? hit.distance : detectionDistance;
    }

    // 투명한 레이캐스트 광선을 에디터 씬 뷰에 그려서 눈으로 확인하는 꿀팁
    private void OnDrawGizmos()
    {
        Gizmos.color = _isDetected ? Color.red : Color.green;
        Gizmos.DrawLine(transform.position, transform.position + transform.right * _lastHitDistance);
    }
}
```

## 5. 실전 활용 예시 (벽 뚫기 방지 대시 스킬)

순간이동 대시를 `transform.position`으로 구현하면 얇은 벽을 뚫고 지나가는 터널링(Tunneling) 버그가 생깁니다. 가려는 거리만큼 미리 박스를 던져보고(`BoxCast`), 막히면 벽 바로 앞까지만 가게 만드는 플랫포머 기법입니다.

```csharp
[RequireComponent(typeof(Collider2D))]
public class BoxCastDash : MonoBehaviour
{
    [SerializeField] private float dashDistance = 4f;
    [SerializeField] private float skinWidth = 0.02f;   // 벽에 딱 달라붙어 끼이는 걸 막는 여백
    [SerializeField] private LayerMask wallLayer;       // 벽 레이어 (나 자신은 절대 제외)

    private Collider2D _col;
    private void Awake() => _col = GetComponent<Collider2D>();

    public void Dash(Vector2 direction)
    {
        Bounds bounds = _col.bounds;
        // 박스 크기를 내 몸보다 아주 살짝 작게 만듦 (여백을 줌)
        Vector2 castSize = (Vector2)bounds.size - (Vector2.one * skinWidth * 2f);

        // 내가 갈 방향으로 내 몸뚱이만 한 박스를 미리 쏴본다
        RaycastHit2D hit = Physics2D.BoxCast(bounds.center, castSize, 0f, direction.normalized, dashDistance, wallLayer);

        // 부딪힌 게 없으면 목표거리(4)만큼 가고, 벽에 걸렸으면 닿기 직전(hit.distance - 0.02)까지만 간다
        float moved = hit.collider == null ? dashDistance : Mathf.Max(hit.distance - skinWidth, 0f);

        transform.position += (Vector3)(direction.normalized * moved);
    }
}
```
> **이 코드가 훌륭한 이유**: 물리 엔진(`Rigidbody`)의 연산을 기다리지 않고, 이동 로직을 내가 100% 통제하면서도 벽 뚫기 버그를 완벽히 막아내는 인디 게임 컨트롤러의 핵심 뼈대입니다.

## 6. Unity 실무 최적화 팁

### 6.1 질의 함수를 매 프레임 `Update`에 쓸 때의 공포 (`All` 계열 피하기)
"내 주위에 폭발 데미지를 줘야지" 하고 `Physics2D.OverlapCircleAll`을 부르면, 범위 안에 있는 모든 콜라이더를 담은 **새로운 배열(Array)이 매번 메모리에 생성**됩니다.\
이를 1초에 60번씩 부르면 유니티 가비지 컬렉터(GC)가 비명을 지르며 게임 프레임이 뚝뚝 떨어집니다.

* **[NonAlloc 방식 쓰기]**\
  매 프레임 여러 마리의 적을 탐지해야 한다면, 미리 텅 빈 리스트나 배열을 클래스 필드에 하나 파두고 거기에 결과물만 채워 넣는 오버로드 함수를 쓰세요.
```csharp
// 1. 재사용할 빈 통을 하나 만들어 둔다.
private Collider2D[] _results = new Collider2D[10]; 

void Update() 
{
    // 2. OverlapCircleNonAlloc은 새 배열을 안 만들고, 저 빈 통에다 쏙쏙 넣어주고 개수만 반환함 (GC 0%)
    int hitCount = Physics2D.OverlapCircleNonAlloc(transform.position, 5f, _results, enemyLayer);
    for(int i = 0; i < hitCount; i++) { /* 뚜까패기 */ }
}
```

### 6.2 2D의 `size`는 전체 크기, 3D의 `halfExtents`는 절반 크기
2D 게임을 만들다가 3D 프로젝트로 넘어갈 때 가장 많이 틀리는 부분입니다.
* `Physics2D.BoxCast`의 두 번째 인자는 박스의 **전체 가로/세로 길이**입니다.
* `Physics.BoxCast(3D)`의 인자는 **절반 크기(반지름 개념)** 입니다. 이 차이를 모르면 3D에서 판정 범위가 2배로 뻥튀기되니 조심하세요.

## 7. 실습 문제 및 복습

**Q1. 점프를 뛰기 전 발밑에 땅이 있는지 검사하기 위해 `Physics2D.Raycast`를 썼습니다. 그런데 점프를 뛰고 허공에 둥둥 떠 있는데도 `isGrounded`가 계속 `true`가 나옵니다. 가장 먼저 의심해야 할 치명적인 실수는 무엇인가요?**
> `LayerMask`에 자기 자신(Player)의 레이어가 포함되어 있는지 확인해야 합니다.\
> 플레이어의 중심에서 광선을 아래로 쐈는데, 자기 자신의 콜라이더를 뚫고 나가면서 "앗! 무언가에 맞았다!"라고 자기 발목을 잡고 바닥으로 착각하는 경우입니다. 마스크에서 `Player` 레이어를 반드시 빼주세요.

**Q2. 투명한 포탈(`Is Trigger` 켜짐)을 통과하는 캐릭터를 만들었습니다. 그런데 적이 플레이어를 향해 쏘는 `Raycast` 시야 판정이 자꾸 포탈에 막혀서 플레이어를 보지 못합니다. 포탈은 놔두면서 시야 광선만 포탈을 무시하게 하려면 어떻게 해야 하나요?**
> `Project Settings ➔ Physics 2D`에 들어가서 **`Queries Start In Colliders`** (질의가 콜라이더 안에서 시작할 때 무시할지 여부)나 **`Queries Hit Triggers`** 체크박스를 끄면 됩니다.\
> `Queries Hit Triggers`를 끄면 씬 전체의 모든 `Raycast`가 트리거(`Is Trigger`)를 무시하고 쌩 지나가서 진짜 딱딱한 벽과 적만 쳐다보게 됩니다.

**Q3. `OnDrawGizmos()` 함수 안에서 화면을 갱신할 때마다 `OverlapCircleAll`을 호출하여 닿은 적들의 테두리를 빨갛게 그리려 합니다. 이 코드의 심각한 문제점은 무엇인가요?**
> `OnDrawGizmos`는 게임이 실행 중이든 아니든 유니티 에디터 화면이 살짝만 움직여도(마우스만 올려도) 수백 번씩 호출되는 시각화 함수입니다. 이 안에서 `All`이 붙은 질의 함수나 무거운 연산을 돌리면 에디터 전체가 버벅이고 가비지(GC)가 미친 듯이 쌓입니다. 질의 연산은 `Update`나 `FixedUpdate`에서만 하고, 기즈모 함수는 계산된 결괏값의 좌표만 받아서 **단순히 선을 그리는(Draw) 역할**만 해야 합니다.

## 8. 주의사항 및 안전 습관

* **광선 출발점을 밖으로 빼라**: 레이캐스트를 쏠 때 웬만하면 `transform.position` 정중앙에서 쏘지 말고, 총구나 발밑처럼 빈 `GameObject`를 하나 만들어서 캐릭터 껍데기 밖에서 쏘세요. (자기 자신 맞춤 방지)
* **`LayerMask`는 하드코딩 금지**: 레이어 번호 8번이 적군이라고 `1 << 8` 이렇게 하드코딩하지 마세요. 나중에 프로젝트 커지면 지옥이 열립니다. 무조건 `[SerializeField] private LayerMask enemyMask;`로 빼서 인스펙터에서 마우스로 똑딱 클릭해서 설정하세요.
* **레이어 매트릭스(Matrix) 맹신 금지**: `Edit ➔ Project Settings`의 충돌 매트릭스에서 체크를 껐다고 해서 `Raycast`가 그 대상을 무시해주지 않습니다. 매트릭스는 "얘네 둘이 부딪히면 튕겨낼까?"라는 **시뮬레이션**만 끕니다. 광선(질의)으로 찾을 때는 무조건 `LayerMask` 변수를 따로 파서 걸러내야 합니다.
