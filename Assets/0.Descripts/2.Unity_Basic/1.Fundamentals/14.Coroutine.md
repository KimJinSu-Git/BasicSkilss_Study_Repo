# [Fundamentals] 14. 코루틴 (Coroutine)

## 1. 코루틴(Coroutine) 이란?
> **타이머를 맞춘 요리사**
> * 오븐에 케이크를 넣고 30분 타이머를 맞춘 요리사(메인 스레드)를 생각해 보세요.
> * 타이머가 울릴 때까지 오븐 앞에서 멍하니 기다리는 대신, 요리사는 **잠시 오븐에서 눈을 떼고 다른 재료를 손질(다른 코드 실행)합니다.**
> * 알람이 울리면, 손질하던 것을 잠시 멈추고 다시 오븐으로 돌아와 하던 일(다음 줄 코드)을 이어서 합니다.
> * 이처럼 **"멈춘 자리를 기억하고 빠져나왔다가, 조건이 맞으면 다시 돌아오는"** 방식이 코루틴입니다.

**왜 필요한가?**\
유니티의 `Update`는 매 프레임 처음부터 끝까지 다 실행되고 끝납니다. "3초 뒤에 수류탄 폭발" 같은 연출을 `Update`로 짜려면, 흐른 시간을 저장할 변수를 파고 `if`문으로 계속 감시해야 해서 코드가 누더기가 됩니다.\
코루틴을 쓰면 **"수류탄 투척 ➔ 3초 대기(`yield`) ➔ 쾅"** 이라는 시간의 흐름을 위에서 아래로 읽히는 깔끔한 한 줄의 소설처럼 쓸 수 있습니다.

## 2. 핵심 요약

| 키워드 | 하는 일 | 기억할 한 줄                                |
| :--- | :--- |:---------------------------------------|
| **`IEnumerator`** | 코루틴 함수의 필수 반환 타입 | 이 껍데기가 없으면 코루틴이 성립하지 않습니다.             |
| **`yield return`** | 실행을 멈추고 제어권을 유니티에 반납 | 이 뒤에 오는 값이 **'언제 다시 돌아올지'** 를 결정합니다.   |
| **`StartCoroutine`** | 만들어진 코루틴을 유니티 엔진에 등록하여 실행 | 함수만 `MyCoroutine();` 부르면 아무 일도 안 일어납니다 |
| **`StopCoroutine`**| 내가 쥐고 있는 특정 코루틴 '핸들'만 멈춤 | 변수에 핸들을 쥐고 있어야 원하는 놈만 암살할 수 있습니다.      |

> **코루틴은 스레드(Thread)가 아닙니다**\
> 코루틴은 다른 차원의 일꾼을 고용하는 멀티스레딩이 아니라, 요리사 한 명(메인 스레드)이 짬을 내서 일을 쪼개 하는 **'협력적 멀티태스킹'** 입니다. 코루틴 안에서 `while(true)`를 돌려놓고 `yield`로 빠져나오지 않으면 유니티 프로그램 전체가 먹통(프리즈)이 됩니다

## 3. 세부 개념 및 원리

### 3.1 코루틴의 기본 구조
```csharp
// 1. 반환 타입은 무조건 IEnumerator
IEnumerator GrenadeRoutine()
{
    Debug.Log("수류탄 투척");

    // 2. yield return으로 제어권을 반납하며 "3초 뒤에 깨워줘" 라고 선언
    yield return new WaitForSeconds(3.0f);   

    // 3. 3초 뒤에 유니티가 다시 이 줄부터 이어서 실행해 줌
    Debug.Log("쾅"); 
}

void Start()
{
    // 4. 그냥 부르면 안 되고, 반드시 StartCoroutine 엔진에 등록해야 돌아갑니다.
    StartCoroutine(GrenadeRoutine());
}
```

### 3.2 시간의 마법사: 주요 `yield` 명령어들
`yield return` 뒤에 무엇을 던져주느냐에 따라 깨어나는 조건이 다릅니다.

| `yield` 명령어 | 깨어나는 시점                  | 실무 활용 시나리오                                  |
| :--- |:-------------------------|:--------------------------------------------|
| `null` | **다음 프레임** (`Update` 직후) | 매 프레임 조금씩 투명해지는 페이드 연출                      |
| `WaitForSeconds(t)` | 게임 시간 **t초 뒤**           | 대사 딜레이, 쿨타임 대기                              |
| `WaitForSecondsRealtime(t)`| 현실 시간 **t초 뒤**           | 게임이 일시정지(`timeScale=0`) 돼도 움직여야 하는 UI 애니메이션 |
| `WaitUntil(() => 조건)` | 조건이 **true**가 될 때        | 보스 체력이 50% 이하가 되면 페이즈 2 시작                  |
| `StartCoroutine(...)` | 다른 코루틴이 다 끝날 때           | '등장 연출 ➔ 대사 ➔ 전투' 순차적 이어붙이기                 |
| `break` | 코루틴 **강제 종료**            | 목표가 죽어서 더 이상 쫓아갈 필요가 없을 때                   |

### 3.3 코루틴의 목줄(Handle) 쥐기
코루틴을 중간에 멈추려면, 쏠 때 그 녀석의 **멱살(Handle)** 을 변수에 쥐고 있어야 합니다.

```csharp
// 완벽한 제어 (Coroutine 핸들 쥐기)
Coroutine _myRoutine;

void StartAttack()
{
    // 코루틴을 쏘면서 핸들을 변수에 저장
    _myRoutine = StartCoroutine(AttackRoutine());
}

void CancelAttack()
{
    // 핸들을 잡고 흔들어서 죽인다
    if (_myRoutine != null) 
    {
        StopCoroutine(_myRoutine);
        _myRoutine = null; // 확인 사살
    }
}
```
> **`StopAllCoroutines()`의 함정**: 이건 핵폭탄입니다. 내가 모르는 남이 돌려놓은 유용한 힐링 코루틴까지 모조리 다 날려버립니다. 무조건 핸들을 쥐고 `StopCoroutine`을 쓰세요.

## 4. 실전 활용 예시 (코루틴 이어 붙이기)

"3, 2, 1 카운트다운 ➔ 끝나면 레이싱 시작"이라는 순차적 연출을 마법처럼 풀어냅니다.

```csharp
public class RaceStarter : MonoBehaviour
{
    private void Start() => StartCoroutine(StartSequence());

    // 메인 감독 코루틴
    private IEnumerator StartSequence()
    {
        // 1. 카운트다운 코루틴을 쏘고, 끝날 때까지 여기서 기다린다
        yield return StartCoroutine(CountDown());    
        
        // 2. 카운트가 완전히 끝난 뒤에야 비로소 달리기가 시작된다
        yield return StartCoroutine(RunForward());   
    }

    private IEnumerator CountDown()
    {
        // 최적화: WaitForSeconds를 매번 new 하지 않고 밖에서 하나 파둠
        WaitForSeconds oneSec = new WaitForSeconds(1f); 

        for (int i = 3; i > 0; i--)
        {
            Debug.Log(i);
            yield return oneSec; // 1초 대기
        }
        Debug.Log("Start");
    }

    private IEnumerator RunForward()
    {
        while (true)
        {
            transform.position += Vector3.forward * (5f * Time.deltaTime);
            yield return null; // 1프레임 쉼
        }
    }
}
```

## 5. Unity 최적화 팁

### 5.1 꺼지면 코루틴은 증발한다
* 오브젝트가 `SetActive(false)`로 비활성화되거나 `Destroy`되면, **그 오브젝트에 매달려 돌아가던 코루틴은 영원히 중지(증발)됩니다.** 다시 `SetActive(true)`로 켜도 이어서 돌지 않습니다
* 그래서 "죽는 몬스터가 자기 사망 이펙트를 코루틴으로 쏘고 스스로 Destroy" 하면 이펙트가 중간에 짤립니다. 이런 시각 연출 코루틴은 죽지 않는 매니저(예: `EffectManager`)에게 던져줘야 합니다.

### 5.2 기다린 뒤엔 세상이 변해있다
```csharp
private IEnumerator AttackRoutine()
{
    // 1초 동안 칼을 들어 올린다.
    yield return new WaitForSeconds(1f);

    // 그 1초 사이에 적이 이미 죽었거나 멀리 도망갔으면? NullReference 폭발
    // target.TakeDamage(10); 

    // 긴 시간 대기 후엔 반드시 타겟이 유효한지 다시 검사해야 한다
    if (target != null && IsInRange(target)) 
        target.TakeDamage(10);
}
```

### 5.3 `new WaitForSeconds`의 가비지(GC) 테러 막기
코루틴 안에서 `yield return new WaitForSeconds(1f);`를 남발하면, 매번 새로운 객체를 메모리에 할당(new)하여 가비지(GC) 렉을 유발합니다.\
**[해결책]**: 쿨타임이나 반복 대기시간이 고정되어 있다면, 클래스 맨 위에 멤버 변수로 캐싱해두고 재사용하세요
```csharp
private readonly WaitForSeconds _waitOneSec = new WaitForSeconds(1f);

private IEnumerator DotDamage()
{
    while(true) {
        yield return _waitOneSec; // new 없이 재사용 (메모리 낭비 0)
    }
}
```

## 6. 실습 문제 및 복습

**Q1. `while(true)` 무한 루프 안에 `yield return null;`을 넣지 않고 코루틴을 쏘면 어떤 끔찍한 일이 벌어지나요?**
> 제어권을 유니티 메인 루프에 돌려주지(yield) 않고 혼자 CPU를 꽉 쥐고 무한대로 돌기 때문에, **유니티 에디터와 게임 전체가 그 자리에서 완전히 먹통(프리즈)이 되어버립니다.** 코루틴 안에서 반복문을 쓸 때는 반드시 `yield`로 숨 쉴 틈을 주어야 합니다.

**Q2. 게임에 일시정지(`Time.timeScale = 0;`) 기능을 넣었습니다. 일시정지 창 안에서 버튼이 0.5초마다 반짝거리는 애니메이션을 코루틴으로 짰는데, 창을 띄우는 순간 반짝거림도 같이 얼어붙습니다. 어떻게 고쳐야 할까요?**
> 반짝임 코루틴 내부에 쓰인 `yield return new WaitForSeconds(0.5f);`를 현실 시간을 기준으로 도는 **`yield return new WaitForSecondsRealtime(0.5f);`** 로 교체해야 타임스케일의 지배를 뚫고 애니메이션이 돌아갑니다.

**Q3. `StopAllCoroutines()`가 편리함에도 불구하고 실무에서 사용을 극도로 꺼리는 이유는 무엇인가요?**
> 내가 멈추고 싶은 A라는 코루틴뿐만 아니라, 다른 팀원이 붙여놓은 유용한 힐링 코루틴이나 배경음악 페이드아웃 코루틴 등 해당 컴포넌트에서 돌고 있는 **내가 모르는 다른 모든 코루틴까지 모조리 학살해 버리기 때문입니다.** 항상 `Coroutine _handle` 변수에 목줄을 쥐고 `StopCoroutine(_handle)`로 정밀 타격해야 합니다.

## 7. 주의사항 및 안전 습관

* **초기화 코루틴의 시작은 `OnEnable`에서**: 풀링 시스템에서 몬스터를 꺼내 쓸 때, `Start()`는 다시 불리지 않습니다. "등장 후 5초 뒤 폭발" 같은 코루틴은 `OnEnable`에서 쏴야 재사용할 때마다 정상 작동합니다.
* **`OnDisable`에서 뒷정리 필수**: 코루틴으로 플레이어의 색깔을 빨간색으로 만들었는데, 0.5초 대기 중에 오브젝트가 꺼져서 코루틴이 증발해버리면 플레이어는 평생 빨간색으로 굳어버립니다. 코루틴으로 만진 상태(색상, 투명도)는 무조건 `OnDisable`에서 원상 복구 시키는 방어 코드를 짜두세요.
* **코루틴은 함수 호출이 아니다**: `MyCoroutine();` 이라고 백날 적어도 아무 일도 일어나지 않습니다. 반드시 `StartCoroutine(MyCoroutine());` 으로 감싸서 쏴야 합니다.
